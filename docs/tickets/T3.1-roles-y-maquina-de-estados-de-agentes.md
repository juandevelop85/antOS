# T3.1 · Orquestador de Roles Multi-Agente (antFlow Core en Rust)

## Descripción
Portar e integrar los principios de orquestación multi-agente de antFlow directamente dentro del demonio `antosd` en Rust, definiendo una máquina de estados para agentes especializados (*Arquitecto, Coder, QA, Auditor*).

## Alcance Técnico
1. **Definición de Roles y Prompts de Sistema:**
   * `Arquitecto`: Planificación técnica, desglose de tickets y validación de arquitectura.
   * `Coder`: Implementación modular de cambios en archivos de código.
   * `QA / Tester`: Generación y ejecución de tests automatizados.
   * `Auditor`: Revisión de seguridad, estilo y diffs antes del merge final.
2. **Máquina de Estados del Ciclo de Vida de Tarea:**
   * Estados: `Pendiente` ➔ `Planificando` ➔ `Implementando` ➔ `VerificandoTests` ➔ `RevisiónAuditor` ➔ `ListoParaAprobacion` ➔ `Fusionado`.
3. **Cola de Tareas en Segundo Plano:**
   * Motor asíncrono con `tokio` dentro de `antosd` que gestiona las transiciones entre agentes.

## Criterios de Aceptación
* Se puede asignar un ticket a la cola de agentes con `antos agent run <ticket_id>`.
* La tarea progresa autónomamente a través de los estados definidos emitiendo eventos por el socket IPC.
