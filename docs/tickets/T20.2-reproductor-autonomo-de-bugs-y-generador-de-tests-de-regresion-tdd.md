# T20.2 · Reproductor Autónomo de Bugs y Generador de Tests de Regresión TDD

> **Estado:** ✅ Completado  
> **Fase:** Fase 20  
> **Fecha:** September 2026

## Descripción
Implementar el subsistema de reproducción autónoma de bugs y generación de pruebas de regresión (*Test-Driven Bug Fixing*) mediante `antos reproduce` y `antos testgen`. Dado un log de error, stack trace, mensaje de panic o descripción de fallo, el sistema crea un worktree efímero de Git, genera un test unitario/integración automatizado que falla replicando el bug exacto (Fase *Red*), y delega en el rol *Coder* la resolución del problema hasta que la suite pase en verde (Fase *Green*), incorporando la prueba permanentemente para evitar regresiones futuras.

## Alcance Técnico
1. **Motor de Ingesta y Diagnóstico de Errores (`system/antosd/src/reproduce.rs`):**
   - Parser de stack traces multilingüe (Rust panics / backtraces, Python tracebacks, JavaScript/TypeScript unhandled rejections).
   - Localización en AST de las funciones, archivos y líneas causantes del fallo.
2. **Generador de Pruebas de Regresión (`testgen`):**
   - Formulación de tests reproducibles aislados en el framework nativo del proyecto (`cargo test`, `pytest`, `jest/vitest`).
   - Verificación de fase *Red*: El test reproduce fielmente el síntoma reportado.
3. **Pipeline TDD Autónomo en Sandbox:**
   - Síntesis del parche correctivo sobre el archivo objetivo (Fase *Green*).
   - Auditoría de seguridad y certificación contra regresiones (Fase *Verified*).
   - Almacenamiento estructurado de artefactos en `.antos/reproduce/<run_id>/`.
4. **Comandos CLI e Integración IPC:**
   - `antos reproduce "<stack trace>"` y `antos reproduce --log <archivo.log>`
   - `antos testgen --target <archivo|módulo> --suite <unit|regression> --cases <N>`
   - Peticiones IPC `Request::ReproduceBug` y `Request::GenerateTest` con emisión de `Event::TddReport`.
   - Capacidades declarativas `test.reproduce` y `test.gen`.
5. **Pruebas y Verificación:**
   - Pruebas unitarias de parsing de stack traces de Rust, Python y JavaScript.
   - Validación del ciclo Red-Green-Verified en sandbox.
   - Pruebas de serialización IPC y planificación de lenguaje natural.

## Criterios de Aceptación
* [x] `antos reproduce` extrae el archivo y función culpable a partir de un stack trace o panic.
* [x] Genera un archivo de test sintácticamente válido que reproduce el fallo en un entorno controlado.
* [x] La suite de tests valida la transición de fallo (Red) a éxito (Green) y certificación (Verified).
* [x] `cargo test --workspace` pasa al 100% sin advertencias ni regresiones (179 tests en antosd + 27 en protocolo + 3 en builder).
