# T20.2 · Reproductor Autónomo de Bugs y Generador de Tests de Regresión TDD

> **Estado:** ⏳ Pendiente  
> **Fase:** Fase 20  
> **Fecha:** September 2026

## Descripción
Implementar el subsistema de reproducción autónoma de bugs y generación de pruebas de regresión (*Test-Driven Bug Fixing*) mediante `antos reproduce` y `antos testgen`. Dado un log de error, stack trace, mensaje de panic o descripción de fallo, el sistema crea un worktree efímero de Git, genera un test unitario/integración automatizado que falla replicando el bug exacto (Fase *Red*), y delega en el rol *Coder* la resolución del problema hasta que la suite pase en verde (Fase *Green*), incorporando la prueba permanentemente para evitar regresiones futuras.

## Alcance Técnico
1. **Motor de Ingesta y Diagnóstico de Errores (`system/antosd/src/reproduce/`):**
   - Parser de stack traces multilingüe (Rust panics / backtraces, Python tracebacks, JavaScript/TypeScript unhandled rejections, C/C++ segfaults).
   - Localización en el grafo de memoria semántica y AST de las funciones, structs y líneas causantes del fallo.
2. **Generador de Pruebas de Regresión (`testgen`):**
   - El rol **QA** formula una prueba mínima reproducible aislada en el framework nativo del proyecto (`cargo test`, `pytest`, `jest`, `vitest`).
   - Verificación de fase *Red*: El test debe fallar con el mismo síntoma reportado.
3. **Pipeline TDD Autónomo en Worktree:**
   - Si la prueba falla coherentemente, se orquesta el *Coder* para escribir el parche mínimo correctivo.
   - Re-ejecución del test en sandbox hasta alcanzar fase *Green*.
   - El *Auditor* certifica que el arreglo no rompa pruebas preexistentes y genera el reporte de regresión.
4. **Comandos CLI e Integración en antFlow:**
   - `antos reproduce "<stack trace o descripción de bug>"`
   - `antos reproduce --log <archivo.log>`
   - `antos testgen --target <función|archivo>`: Genera tests de cobertura de casos esquina para una función específica.
5. **Pruebas y Verificación:**
   - Pruebas unitarias de parsing de stack traces de Rust y Python.
   - Validación del ciclo Red-Green en un proyecto de prueba aislado en sandbox.

## Criterios de Aceptación
* `antos reproduce` extrae el archivo y función culpable a partir de un stack trace o panic.
* Genera un archivo de test sintácticamente válido que reproduce el fallo en un worktree.
* La suite de tests valida la transición de fallo (Red) a éxito (Green).
* `cargo test --workspace` pasa al 100% sin advertencias ni regresiones.
