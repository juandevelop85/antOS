# T24.2 · Empaquetador de Ramdisk (Initramfs) Live con Sistema Base y Herramientas

> **Estado:** ⏳ Pendiente  
> **Fase:** Fase 24  
> **Fecha:** September 2026

## Descripción
Diseñar e implementar el empaquetador de la imagen de disco en memoria RAM (*Initramfs / Live Ramdisk*) para antOS. Al arrancar desde una memoria USB o medio óptico en una máquina física, el sistema operativo no debe tocar el disco duro interno de inmediato. En su lugar, el cargador de arranque transfiere un archivo comprimido `initrd.img` a memoria RAM, el cual es montado por el kernel como el sistema de ficheros raíz temporal (`/`). Este entorno Live contiene los ejecutables esenciales de userspace, bibliotecas, utilidades de particionado y el asistente de instalación guiada.

## Alcance Técnico
1. **Formato y Compresión del Ramdisk:**
   - Soporte para formato archivo CPIO / USTAR con compresión opcional (Gzip o Zstandard).
   - Generación del archivo `initrd.img` durante el pipeline de construcción de la imagen de instalación (`antos boot iso` / `builder`).
2. **Estructura de Directorios del Entorno Live:**
   - `/bin`: Ejecutables esenciales (`antos`, `antosd`, `sh`, `parted`, `mkfs.ext4`).
   - `/sbin/init`: Enlace simbólico o binario de inicialización de espacio de usuario (`antos-init`).
   - `/etc`: Ficheros declarativos mínimos (`hostname`, `os-release`, `fstab` tipo tmpfs).
   - `/dev`, `/proc`, `/sys`, `/mnt`, `/tmp`: Puntos de montaje virtuales del sistema operativo.
3. **Integración con Limine Bootloader:**
   - Añadir la directiva de módulo en `limine.conf`:
     ```text
     module_path: boot():/initrd.img
     ```
   - El bootloader entrega el puntero físico y tamaño del ramdisk al kernel en la estructura de arranque.
4. **Montaje y Transición en el Kernel (`kernel/src/fs/ramdisk.rs`):**
   - El kernel desempaqueta o mapea el initramfs en memoria, monta el sistema de archivos raíz en RAM (`rootfs / tmpfs`) y transiciona al primer proceso de usuario (`/bin/init` o `antosd`).
5. **Pruebas y Verificación:**
   - Prueba unitaria de serialización y lectura de la cabecera del ramdisk.
   - Verificación de que el kernel arranca y ejecuta comandos básicos contenidos en el ramdisk sin acceso a disco persistente.

## Criterios de Aceptación
* Se implementa la herramienta o función que genera automáticamente el archivo `initrd.img`.
* El fichero `limine.conf` incluye la directiva `module_path` apuntando al ramdisk.
* El kernel detecta el ramdisk entregado por el bootloader y monta el rootfs en RAM.
* El entorno de usuario puede listar ficheros y ejecutar binarios directamente desde el Live Ramdisk.
* `cargo test --workspace` compila y pasa con 0 errores.
