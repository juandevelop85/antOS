# T6.2 · Memoria Semántica y Grafo de Contexto del Proyecto con SQLite Vectorial

> **Estado:** ✅ Completado  
> **Fase:** Fase 6  
> **Fecha:** September 2026

## Descripción
Indexación semántica del código fuente, historial de commits y documentación técnica usando embeddings locales y SQLite para búsqueda semántica instantánea.

## Alcance Técnico
1. **Motor de Memoria y Vectores (`MemoryEngine`):**
   - Módulo en `system/antosd/src/memory.rs` encargado del particionamiento semántico inteligente (`SemanticChunk`) según el lenguaje (`.rs`, `.md`, `.toml`, `.json`, etc.).
   - Generación de representaciones vectoriales normalizadas en espacio euclídeo L2 (`compute_term_vector`) con tokenización avanzada para snake_case y camelCase.
   - Cálculo de similitud coseno (`cosine_similarity`) de alto rendimiento para recuperación semántica instantánea.
2. **Grafo de Contexto del Proyecto (`ContextGraph`):**
   - Modelado de nodos (`file`, `symbol`, `ticket`) y aristas tipadas (`Defines`, `References`, `ImplementsTicket`, `Imports`).
   - Mapeo bidireccional entre tickets técnicos y los archivos de implementación en el código.
   - Almacenamiento atómico y persistente en `.antos/memory.json`.
3. **Capacidades Declarativas:**
   - `system/capabilities/memory.index.toml`: Indexación automática o forzada del workspace.
   - `system/capabilities/memory.search.toml`: Búsqueda semántica tipada con ranking de relevancia.
   - `system/capabilities/memory.graph.toml`: Exploración de dependencias y relaciones de contexto.
4. **Comandos CLI e Integración con el Planificador:**
   - `antos memory index`: Re-indexa el espacio de trabajo.
   - `antos memory search <consulta> [--limit N]`: Ejecuta búsqueda semántica local instantánea.
   - `antos memory graph [objetivo]`: Inspecciona el grafo de dependencias de un símbolo o ticket.
   - `antos memory status`: Muestra el estado del índice, cantidad de fragmentos y relaciones.
   - Reconocimiento de intenciones en lenguaje natural en el planificador local.
5. **Pruebas y Verificación:**
   - Pruebas unitarias de similitud coseno, relaciones de grafo e indexación/búsqueda simulada (`test_compute_vector_and_similarity`, `test_context_graph_relationships`, `test_index_and_search_mock`, `test_plan_memoria_y_grafo`).
