# T20.1 · Espacio de Trabajo Integrado Dev TUI con Neovim, Monitor de Agentes y Visor de Diffs

> **Estado:** ✅ Completado  
> **Fase:** Fase 20  
> **Fecha:** September 2026

## Descripción
Construir un entorno de trabajo integrado interactivo en terminal (*Dev TUI Multiplexer*) accesible mediante el comando `antos dev` (y atajo de escritorio `Super + W`). Este espacio de trabajo combina la edición de código de ultra-baja latencia con Neovim, la visualización en tiempo real del progreso del equipo de agentes (`antFlow`), el visor de diffs y árbol Git, y un terminal flotante/inferior de ejecución interactiva (`VTE`), eliminando la fricción de gestionar múltiples ventanas o emuladores de terminal externos.

## Alcance Técnico
1. **Layout y Motor TUI de Múltiples Paneles (`system/antosd/src/dev_tui/`):**
   - Panel Principal (Editor): Sesión de Neovim (`nvim`) con autoconfiguración activa hacia `antos-lsp`.
   - Panel Lateral Superior: Monitor de telemetría de agentes (`antFlow`), transiciones de fase, rol activo y modelo LLM en ejecución.
   - Panel Lateral Inferior: Árbol de archivos y visor de diffs sintácticos coloreados del proyecto o worktree activo.
   - Panel Inferior Desplegable: Consola interactiva VTE para ejecución de pruebas y comandos bash/zsh bajo demanda.
2. **Navegación y Atajos de Teclado del Espacio de Trabajo:**
   - `Ctrl + W + h/j/k/l` o `Alt + Flechas`: Conmutación instantánea entre paneles.
   - `Ctrl + Space`: Alternar visibilidad del monitor lateral de agentes.
   - `Ctrl + T`: Desplegar / ocultar terminal VTE inferior.
   - `Ctrl + Q`: Salida ordenada y guardado de sesión.
3. **Integración IPC y Capacidad Declarativa:**
   - Capacidad `dev.workspace`: Permite arrancar, diagnosticar y restaurar la sesión TUI.
   - Eventos de redibujado reactivo: Cuando `antFlow` emite un evento `FlowTransition`, el panel de agentes se actualiza en tiempo real sin interferir en el cursor de Neovim.
4. **Comandos CLI e Integración Wayland:**
   - `antos dev`: Inicia el espacio de trabajo en la terminal actual.
   - `antos dev --project <p>`: Abre directamente un proyecto específico del workspace.
   - Atajo de teclado en `system/desktop/rc.xml`: `Super + W` para abrir `antos dev` en una nueva ventana flotante.
5. **Pruebas y Verificación:**
   - Pruebas unitarias de inicialización y cálculo de dimensiones de layout de paneles.
   - Verificación de no interferencia con stdio en sesiones no interactivas (headless).

## Criterios de Aceptación
* `antos dev` arranca el layout multi-panel integrando Neovim y el monitor de antOS.
* Las transiciones de agentes se reflejan en vivo en el panel lateral correspondiente.
* Los atajos de navegación permiten cambiar el foco fluidamente entre el editor y los paneles auxiliares.
* `cargo test --workspace` pasa al 100% sin advertencias ni regresiones.
