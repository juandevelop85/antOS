# T21.3 · Generador y Sincronizador de Documentación Viva de Arquitectura y Diagramas Mermaid

> **Estado:** ⏳ Pendiente  
> **Fase:** Fase 21  
> **Fecha:** September 2026

## Descripción
Implementar el subsistema de documentación viva y generación automática de diagramas arquitectónicos (`antos doc arch`), capaz de mantener la documentación del repositorio permanentemente sincronizada con el código fuente real. A partir del análisis del AST, las dependencias entre crates y módulos, los contratos IPC de `antos_protocolo` y los endpoints de servicios, el sistema genera diagramas Mermaid (diagramas de flujo, grafos de dependencias C4 y secuencias de eventos) integrándolos automáticamente en los documentos de arquitectura y READMEs del proyecto.

## Alcance Técnico
1. **Extractor de Topología Arquitectónica y AST (`system/antosd/src/doc_arch/`):**
   - Análisis sintáctico del workspace: crates, módulos internos, traits públicos y dependencias directas/transitivas.
   - Mapeo de tipos de mensajes IPC (`Request`, `Response`, `Event`) de `system/protocolo`.
   - Extracción de dependencias externas declaradas en `Cargo.toml` / `package.json`.
2. **Generador de Diagramas Mermaid:**
   - Diagrama de Componentes C4: Módulos del sistema (`kernel`, `antosd`, `capabilities`, `barra`) y fronteras de sandbox.
   - Diagrama de Flujo de Datos IPC: Ciclo de vida de intenciones y eventos reactivos.
   - Diagrama de Máquina de Estados: Estados de `antFlow` y roles involucrados.
3. **Sincronización Viva con Documentación Markdown:**
   - Inserción y actualización in-place de bloques delimitados `<!-- ANTOS_ARCH_START -->` ... `<!-- ANTOS_ARCH_END -->` en archivos de documentación técnica (`README.md`, `docs/arquitectura.md`).
   - El rol *Arquitecto* de antFlow actualiza automáticamente estos diagramas cuando un ticket introduce nuevos crates o tipos IPC.
4. **Comandos CLI:**
   - `antos doc arch`: Imprime o exporta el diagrama de arquitectura completo en formato Mermaid o SVG.
   - `antos doc sync`: Escanea la documentación del repositorio y actualiza todos los diagramas de arquitectura obsoletos.
   - `antos doc check`: Modo CI para verificar si la documentación está sincronizada con el código (falla si hay divergencia).
5. **Pruebas y Verificación:**
   - Pruebas unitarias de generación sintáctica de diagramas Mermaid válidos.
   - Verificación de inserción y reemplazo correcto en archivos markdown sin alterar contenido adyacente.

## Criterios de Aceptación
* `antos doc arch` genera diagramas Mermaid válidos reflejando los crates y módulos reales del workspace.
* `antos doc sync` actualiza los bloques delimitados en archivos markdown sin borrar comentarios ni texto manual.
* `antos doc check` retorna error si el código fue modificado pero la arquitectura no fue actualizada.
* `cargo test --workspace` pasa al 100% sin advertencias ni regresiones.
