# T21.3 · Generador y Sincronizador de Documentación Viva de Arquitectura y Diagramas Mermaid

> **Estado:** ✅ Completado  
> **Fase:** Fase 21  
> **Fecha:** September 2026

## Descripción
Implementar el subsistema de documentación viva y generación automática de diagramas arquitectónicos (`antos doc arch`), capaz de mantener la documentación del repositorio permanentemente sincronizada con el código fuente real. A partir del análisis del AST, las dependencias entre crates y módulos, los contratos IPC de `antos_protocolo` y los endpoints de servicios, el sistema genera diagramas Mermaid (diagramas de flujo, grafos de dependencias C4 y secuencias de eventos) integrándolos automáticamente en los documentos de arquitectura y READMEs del proyecto.

## Alcance Técnico
1. **Extractor de Topología Arquitectónica y AST (`system/antosd/src/doc_arch.rs`):**
   - Análisis sintáctico del workspace: 6 crates (`kernel`, `builder`, `system/protocolo`, `system/antosd`, `system/capabilities`, `system/barra`), 53 módulos internos de `antosd`, traits públicos y dependencias.
   - Mapeo dinámico de contratos IPC de `system/protocolo` (97 peticiones y 91 eventos).
   - Mapeo del catálogo de 113 capacidades declarativas clasificadas por políticas de seguridad (`auto`, `confirm`, `grant`).
2. **Generador de Diagramas Mermaid (`DocArchEngine`):**
   - **Diagrama de Componentes C4 / Topología (`components`):** Visualización modular de subsistemas, interfaces y fronteras de sandbox (*Seatbelt / Landlock LSM*).
   - **Diagrama de Flujo de Datos IPC (`flow`):** Secuencia de ejecución de intenciones, despacho IPC, sandbox y bitácora atómica.
   - **Diagrama de Máquina de Estados antFlow (`antflow`):** Ciclo de vida entre roles (*Arquitecto, Coder, QA, Auditor, BenchDiff, Forge*).
   - **Modo Completo (`full`):** Consolidación estructurada de todas las vistas arquitectónicas.
3. **Sincronización Viva con Documentación Markdown:**
   - Inserción y actualización in-place con bloques delimitados `<!-- ANTOS_ARCH_START -->` ... `<!-- ANTOS_ARCH_END -->` en archivos de documentación técnica (`docs/arquitectura.md`, `README.md`).
   - Preservación íntegra de texto manual, cabeceras y notas adyacentes.
   - Modo CI (`doc check`) que detecta divergencias entre el código y la documentación retornando código de error si está desactualizada.
4. **Comandos CLI y Capacidades Declarativas:**
   - `antos doc arch [--type <components|flow|antflow|all>] [--output <file>]`
   - `antos doc sync [--file <path>]`
   - `antos doc check [--file <path>]`
   - Capacidades: `doc.arch.toml`, `doc.sync.toml`, `doc.check.toml`.
   - Protocolo IPC: `Request::{GenerateArchDiagram, SyncArchDocs, CheckArchDocs}` y eventos `Event::{ArchDiagram, DocSync}`.
5. **Pruebas y Verificación:**
   - Pruebas unitarias en `system/protocolo`: `test_arch_doc_serialization`.
   - Pruebas unitarias en `system/antosd/src/doc_arch.rs`: `test_topology_analysis_on_workspace`, `test_generate_mermaid_diagrams`, `test_markdown_in_place_synchronization_and_check`.
   - Pruebas de planificador en `system/antosd/src/planner/local.rs`: `test_plan_doc_arch_and_sync`.

## Criterios de Aceptación
* [x] `antos doc arch` genera diagramas Mermaid válidos reflejando los crates y módulos reales del workspace.
* [x] `antos doc sync` actualiza los bloques delimitados en archivos markdown sin borrar comentarios ni texto manual.
* [x] `antos doc check` retorna error si el código fue modificado pero la arquitectura no fue actualizada.
* [x] `cargo test --workspace` pasa al 100% sin advertencias ni regresiones (198 tests en antosd + 32 en protocolo + 3 en builder).
