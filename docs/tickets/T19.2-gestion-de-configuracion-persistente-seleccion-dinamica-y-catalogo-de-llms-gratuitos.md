# T19.2 · Gestión de Configuración Persistente, Selección Dinámica y Catálogo de LLMs Gratuitos

> **Estado:** ✅ Completado  
> **Fase:** Fase 19  
> **Fecha:** September 2026

## Descripción
Implementar el subsistema de configuración persistente de LLMs en `system/antosd/src/llm/`, permitiendo que el usuario consulte, alterne y gestione dinámicamente el motor de inferencia activo del sistema operativo mediante comandos CLI dedicados (`antos llm`). Incluir un catálogo curado e interactivo de modelos 100% gratuitos (`antos llm free`) para que cualquier desarrollador pueda usar IA avanzada en antOS sin coste alguno.

## Alcance Técnico
1. **Configuración Persistente (`system/antosd/src/llm/config.rs`):**
   - Archivo de configuración en `state/llm_config.json`.
   - Soporte para proveedor activo, modelo predeterminado, endpoints por proveedor y sobreescrituras por rol de agente.
   - Enrutador de planificadores con jerarquía de fallback transparente:
     `Proveedor Seleccionado -> Ollama Local -> Planificador Determinista Local`.
2. **Comandos CLI Enriquecidos (`system/antosd/src/main.rs`):**
   - `antos llm status`: Diagnóstico exhaustivo que muestra el proveedor activo, modelo en uso, endpoint, latencia de respuesta, estado de conexión y presencia de credenciales en bóveda.
   - `antos llm list` / `antos llm models`: Lista de modelos locales descargados en Ollama y modelos configurados en la nube.
   - `antos llm use <proveedor> [--model <modelo>]`: Conmutación dinámica e instantánea del proveedor de inferencia activo.
     - Ejemplos: `antos llm use ollama --model qwen2.5-coder`, `antos llm use groq --model llama-3.3-70b-versatile`, `antos llm use openrouter --model deepseek/deepseek-r1:free`, `antos llm use opencode --endpoint http://localhost:8080/v1`.
   - `antos llm free`: Catálogo interactivo de modelos y servicios 100% gratuitos (offline locales y cloud tiers gratuitos) con instrucciones paso a paso para activarlos con un único comando.
   - `antos llm test [--prompt "..."]`: Verificación interactiva de inferencia y llamada a herramientas en tiempo real sobre el modelo activo.
3. **Pruebas y Verificación:**
   - Pruebas unitarias de carga, guardado, actualización y fallback de configuración en `llm_config.json`.

## Criterios de Aceptación
* El comando `antos llm use` actualiza persistentemente la configuración y cambia el motor que atiende las intenciones del usuario.
* `antos llm free` muestra la lista de opciones gratuitas recomendadas y cómo configurarlas.
* `antos llm status` reporta con precisión el estado y latencia de los motores locales y remotos.
* `cargo test --workspace` pasa al 100% sin regresiones.
