# T19.1 · Motor de Inferencia OpenAI-Compatible y Hub de Proveedores Gratuitos

> **Estado:** ✅ Completado  
> **Fase:** Fase 19  
> **Fecha:** September 2026

## Descripción
Implementar el planificador universal `OpenAiCompatPlanner` en `system/antosd/src/planner/openai_compat.rs`, capaz de comunicarse con cualquier servidor de inferencia que implemente la API estándar `/v1/chat/completions` con soporte para llamadas estructuradas a herramientas (*Tool Calling / Function Calling*). Integrar adaptadores y preajustes para proveedores que ofrecen tiers gratuitos sin tarjeta de crédito (OpenRouter Free, Groq Cloud Free, Google Gemini API Free) y motores locales independientes (OpenCode, llama.cpp server, LocalAI, vLLM).

## Alcance Técnico
1. **Cliente HTTP y Protocolo `/v1/chat/completions`:**
   - Estructuración de peticiones con `messages` (system prompt con catálogo de capacidades tipadas) y `tools` (esquema JSON Schema de cada capacidad de antOS).
   - Parseo robusto de respuestas: soporte tanto de `tool_calls` nativo como de fallback a extracción de JSON estructurado en el contenido del mensaje.
2. **Preajustes de Proveedores Gratuitos y Locales:**
   - **OpenRouter Free Tier:** Endpoint `https://openrouter.ai/api/v1`, preconfigurado para modelos como `deepseek/deepseek-r1:free`, `qwen/qwen-2.5-coder-32b-instruct:free`, `meta-llama/llama-3.3-70b-instruct:free`.
   - **Groq Cloud Free:** Endpoint `https://api.groq.com/openai/v1`, preconfigurado para inferencia de ultra-baja latencia con `llama-3.3-70b-versatile` y `deepseek-r1-distill-llama-70b`.
   - **Google Gemini API Free:** Endpoint OpenAI-compatible de Google `https://generativelanguage.googleapis.com/v1beta/openai/`, preconfigurado para `gemini-2.0-flash` y `gemini-1.5-flash`.
   - **OpenCode / llama.cpp / vLLM:** Endpoint local configurable (por defecto `http://127.0.0.1:8080/v1` o `http://127.0.0.1:11434/v1`).
3. **Integración con Bóveda de Secretos (`system/antosd/src/vault.rs`):**
   - Lectura segura de claves de autenticación desde la boveda de antOS (`OPENROUTER_API_KEY`, `GROQ_API_KEY`, `GEMINI_API_KEY`) sin filtrarlas a variables de entorno de procesos hijos no confiables.
4. **Pruebas y Verificación:**
   - Pruebas unitarias de serialización de esquemas de herramientas y deserialización de respuestas con tool calls y formato JSON fallback.

## Criterios de Aceptación
* `OpenAiCompatPlanner` traduce intenciones del usuario en secuencias de capacidades (`Step`) válidas contra el catálogo de antOS.
* Es posible configurar endpoints personalizados y modelos arbitrarios mediante variables o configuración estructurada.
* Los proveedores con modelos gratuitos funcionan utilizando su API key almacenada en la bóveda o en entorno.
* `cargo test --workspace` pasa al 100% sin advertencias ni regresiones.
