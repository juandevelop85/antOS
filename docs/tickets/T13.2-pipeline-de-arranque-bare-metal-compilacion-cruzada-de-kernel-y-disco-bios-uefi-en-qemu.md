# T13.2 · Pipeline de Arranque Bare Metal, Compilación Cruzada de Kernel y Disco BIOS/UEFI en QEMU

> **Estado:** ⏳ Pendiente  
> **Fase:** Fase 13  
> **Fecha:** September 2026

## Descripción
Consolidación y automatización del pipeline de arranque bare metal del núcleo `no_std` de antOS (`kernel/`) y el generador de imágenes de disco (`builder/`), permitiendo compilar para la arquitectura destino `x86_64-unknown-none`, crear imágenes híbridas BIOS/UEFI (`antos-bios.img`) e iniciar la ejecución con salida de diagnóstico por puerto serie UART 16550 hacia QEMU.

## Alcance Técnico
1. **Compilación Cruzada del Kernel (`kernel/`):**
   - Asegurar compilación limpia sin advertencias bajo target `x86_64-unknown-none` con Rust nightly.
   - Implementación de driver de consola UART 16550 serial sobre puerto `0x3F8` para telemetría inicial de arranque del núcleo.
   - Paginación y mapa de memoria física inicial para el kernel.
2. **Generador de Disco de Arranque (`builder/`):**
   - Creación de imagen de disco con tabla de particiones MBR/GPT y sector de arranque BIOS/UEFI.
   - Empaquetado del binario ELF del kernel en la imagen final.
3. **Automatización de Ejecución y Pruebas (`run.sh`):**
   - Pipeline de compilación, construcción de imagen y arranque de `qemu-system-x86_64` con `-serial stdio` y `-display none` o ventana gráfica.
   - Script de prueba headless automatizado que capture el mensaje de inicialización del kernel y verifique el arranque sin cuelgues.
4. **Comando CLI de antOS:**
   - `antos boot [build|qemu|test]`: Control directo del pipeline de arranque desde la herramienta CLI principal.

## Criterios de Aceptación
* El kernel `no_std` compila limpiamente para `x86_64-unknown-none`.
* La imagen de disco arranca exitosamente en QEMU emitiendo el banner de antOS por el puerto serie serial.
* Nomenclatura e identificadores en Rust 100% en inglés.
