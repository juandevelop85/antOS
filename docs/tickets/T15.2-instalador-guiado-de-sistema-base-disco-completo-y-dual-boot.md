# T15.2 · Instalador Guiado de Sistema Base (Disco Completo y Dual Boot)

> **Estado:** ✅ Completado  
> **Fase:** Fase 15  
> **Fecha:** September 2026

## Descripción
Creación del motor de instalación de antOS para transferir el sistema operativo completo desde un medio Live USB o imagen de instalación hacia el disco de destino (NVMe/SSD). El instalador debe permitir dos modos principales: instalación limpia como **sistema operativo principal** (borrando el disco entero) o instalación en **Dual Boot como sistema secundario** (instalando antOS en particiones asignadas sin perturbar la instalación existente de Windows u otro Linux).

## Alcance Técnico
1. **Motor de Instalación y Despliegue (`system/antosd/src/installer/deploy.rs`):**
   - Formateo de particiones:
     - Partición EFI: Formateo en FAT32 (`mkfs.vfat -F32`).
     - Partición Raíz: Formateo en ext4 (`mkfs.ext4 -L "antOS"`) o btrfs.
   - Montaje jerárquico temporal en `/mnt/antos` (`/mnt/antos/boot/efi`).
   - Transferencia y sincronización del sistema base: copia de binarios (`antos`, `antosd`, `builder`), capacidades declarativas (`/etc/antos/capabilities`), perfiles nixos base, librerías y configuración de red.
2. **Configuración Inicial del Sistema Destino:**
   - Generación del archivo `/etc/fstab` basado en UUIDs de partición persistentes (`UUID=...`).
   - Configuración de hostname, zona horaria y usuario administrador por defecto (`antos` con sudoers).
   - Habilitación del servicio `antosd` en systemd (`systemctl enable antosd`).
3. **Capacidades Declarativas:**
   - `install.prepare`: Prepara el punto de montaje y verifica requerimientos de espacio (mínimo 8 GB).
   - `install.deploy`: Ejecuta la transferencia de archivos y configuración base.
4. **Comandos CLI e Interfaz Guiada:**
   - `antos install gui`: Asistente interactivo guiado paso a paso por terminal o ventana gráfica.
   - `antos install run --target <disco> [--mode clean|dual-boot] [--user <nombre>]`: Despliegue automatizado no interactivo.
5. **Pruebas y Verificación:**
   - Pruebas unitarias de generación de `fstab`, cálculo de cuotas de espacio y parseo de parámetros de instalación.

## Criterios de Aceptación
* El instalador transfiere los archivos requeridos y genera un sistema de archivos arrancable con UUIDs únicos.
* Soporte para instalación limpia y convivencia pacífica en particiones dedicadas (Dual Boot).
* `cargo test --workspace` pasa al 100% sin advertencias.
* Nomenclatura e identificadores en Rust 100% en inglés.
