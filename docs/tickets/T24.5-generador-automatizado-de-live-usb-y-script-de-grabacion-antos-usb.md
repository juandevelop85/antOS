# T24.5 · Generador Automatizado de Live USB y Script de Grabación (`antos usb flash`)

> **Estado:** ✅ Completado  
> **Fase:** Fase 24  
> **Fecha:** September 2026

## Descripción
Simplificar para el desarrollador y el usuario la creación de memorias USB de instalación booteables de antOS mediante comandos nativos del CLI (`antos usb build` y `antos usb flash`). Actualmente, la generación de imágenes y su volcado en medios extraíbles requiere comandos manuales de bajo nivel con `dd` o utilidades externas, con el riesgo latente de sobreescribir por error unidades de almacenamiento internas del sistema anfitrión. Este ticket automatiza el empaquetado de la imagen híbrida final y proporciona un grabador seguro con protección de discos del sistema, verificación SHA-256 y compatibilidad con herramientas de terceros como Rufus, BalenaEtcher y Ventoy.

## Alcance Técnico
1. **Comando `antos usb build` (`system/antosd/src/installer/usb.rs`):**
   - Orquesta la compilación del kernel, el empaquetado del initramfs y el ensamblado de la imagen ISO híbrida mediante `builder` en un único paso:
     ```bash
     antos usb build [--arch x86_64|aarch64] [--out antos-installer.iso]
     ```
   - Genera el archivo de suma de verificación `antos-installer.iso.sha256`.
2. **Comando `antos usb flash` con Detección Segura de Medios Extraíbles:**
   - Inspección segura de unidades mediante `diskutil list` en macOS o `lsblk -d -o NAME,SIZE,TYPE,TRAN` en Linux.
   - **Mecanismos de Protección Crítica:**
     - Exclusión automática de discos internos del sistema (`internal` / bus `NVMe` / bus `SATA` principal).
     - Solo se muestran como destinos elegibles unidades con bus `USB` o marcadas como extraíbles (`RM=1`).
   - Confirmación explícita con nombre del fabricante, tamaño del pendrive y ruta de dispositivo antes de proceder a la escritura.
3. **Grabación Bit a Bit y Verificación:**
   - Desmontaje previo de las particiones del pendrive.
   - Escritura mediante streaming en bloques de 4 MiB con reporte de progreso en tiempo real (MB/s transcurridos y porcentaje).
   - Forzado de sincronización a hardware (`fsync` / `sync`).
   - Lectura y comprobación del hash SHA-256 de los bloques escritos para certificar que la memoria USB no contiene sectores corruptos.
4. **Compatibilidad con Gestores Multiboot:**
   - Asegurar que la ISO generada funcione sin modificaciones con **Ventoy** (arranque directo ISO multiboot) y **Rufus** (modo DD y modo ISO).
5. **Documentación del Flujo de Instalación Física:**
   - Crear la guía completa `docs/guia-live-usb-e-instalacion-fisica.md` con instrucciones paso a paso para usuarios finales.

## Criterios de Aceptación
* `antos usb build` genera la imagen ISO híbrida booteable de antOS con su correspondiente checksum.
* `antos usb flash` detecta y lista exclusivamente memorias USB conectadas, bloqueando cualquier intento sobre discos internos.
* El proceso de volcado reporta barra de progreso en vivo y valida la integridad de los datos grabados.
* La memoria USB generada arranca en una PC física o laptop y ejecuta la sesión Live de antOS.
* `cargo test --workspace` compila y pasa con 0 errores.
