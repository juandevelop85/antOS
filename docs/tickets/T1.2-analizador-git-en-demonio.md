# T1.2 · Analizador de Repositorios Git en Segundo Plano en `antosd`

## Descripción
Implementar el motor de análisis e introspección de repositorios Git dentro del demonio `antosd` utilizando Rust de bajo nivel (vía `gix` o `libgit2`), respondiendo a las consultas de estado en milisegundos sin bloquear el bucle de eventos.

## Alcance Técnico
1. **Lógica de Introspección Git:**
   * Detección de raíz de repositorio (`.git`) a partir de cualquier subdirectorio.
   * Obtención rápida del HEAD, rama local y upstream remoto.
   * Cálculo de archivos modificados, staged y no rastreados con recuento de líneas modificadas.
2. **Caché en Memoria y Monitor de Cambios:**
   * Estructura de caché para responder inmediatamente.
   * Invalidación inteligente ante eventos de modificación en `.git/index` y `.git/HEAD`.
3. **Manejador en el Demonio:**
   * Integración del mensaje `ConsultarEstadoGit` en el despachador de conexiones de `antosd`.

## Criterios de Aceptación
* Respuesta a consultas de estado Git en < 30 ms en repositorios con más de 10.000 archivos.
* Manejo seguro de casos sin repo Git o repositorios vacíos/iniciales.
