# T25.2 · Gestor y Puente de Aplicaciones Flatpak y Contenedores Gráficos (`antos app`)

> **Estado:** ✅ Completado  
> **Fase:** Fase 25  
> **Fecha:** Septiembre 2026

## Descripción
Implementar un subsistema unificado para la gestión e integración de aplicaciones de escritorio empaquetadas en Flatpak dentro de antOS. Flatpak es el estándar en distribuciones inmutables modernas (como NixOS o Silverblue) para ejecutar navegadores (Google Chrome, Firefox, Brave) e IDEs pesados (VS Code, JetBrains, Postman) con aislamiento nativo vía Bubblewrap y portales Wayland. Este ticket dota a `antosd` de un módulo orquestador de Flatpak, un protocolo IPC tipado y el comando CLI `antos app`.

## Alcance Técnico
1. **Modelos y Protocolo IPC (`system/protocolo`):**
   - Estructuras:
     - `AppSource` (`Flatpak`, `NativePkg`, `Nix`).
     - `DesktopApp`: ID (ej. `com.visualstudio.code`), nombre, versión, fuente, descripción, icono, permisos/sandboxing.
     - `AppInstallRequest`, `AppUninstallRequest`, `AppLaunchRequest`, `AppSearchResult`.
   - Peticiones y eventos IPC:
     - `ListDesktopApps`, `SearchRemoteApps`, `InstallDesktopApp`, `UninstallDesktopApp`, `LaunchDesktopApp`.
     - `Event::AppProgress` (reporte de descarga e instalación asíncrona).
2. **Motor de Aplicaciones en Demonio (`system/antosd/src/apps/`):**
   - Crear módulo `system/antosd/src/apps/mod.rs` y `system/antosd/src/apps/flatpak.rs`.
   - Detección de binario `flatpak` en el sistema base y configuración automática del repositorio Flathub (`flathub.flatpakrepo`).
   - Operaciones tipadas sin bloqueo:
     - Búsqueda e indexación de aplicaciones Flathub.
     - Instalación y desinstalación con emisión de eventos de progreso al socket IPC.
     - Lanzamiento de aplicaciones inyectando variables de entorno del sistema (`WAYLAND_DISPLAY`, `XDG_CURRENT_DESKTOP=antOS`, `ANTOS_WORKSPACE`, `ANTOS_SOCKET`).
3. **Capacidades Declarativas:**
   - `app.install`: Instala una aplicación gráfica desde Flatpak o el almacén del sistema.
   - `app.list`: Enumera todas las aplicaciones de escritorio instaladas.
   - `app.launch`: Ejecuta una aplicación vinculándola al contexto del workspace activo.
   - `app.uninstall`: Elimina una aplicación y revoca sus permisos.
4. **Comandos CLI en antOS:**
   - `antos app list`: Lista todas las aplicaciones de escritorio instaladas y su origen.
   - `antos app search <término>`: Busca aplicaciones disponibles en Flathub y recetas antOS.
   - `antos app install <id>`: Descarga e instala una aplicación (ej. `antos app install com.visualstudio.code`).
   - `antos app run <id> [--workspace <dir>]`: Lanza la aplicación vinculada al workspace actual.
   - `antos app remove <id>`: Desinstala la aplicación.
5. **Pruebas y Verificación:**
   - Mocking de interfaz Flatpak en entornos de prueba unitaria sin binario Flatpak real.
   - Verificación de serialización/deserialización de mensajes IPC de aplicaciones.
   - 100% de compatibilidad con `cargo test --workspace`.

## Criterios de Aceptación
* El demonio `antosd` detecta y orquesta aplicaciones Flatpak de forma asíncrona y estructurada.
* Los comandos `antos app search/install/list/run/remove` permiten administrar aplicaciones gráficas desde la terminal o mediante IPC.
* La ejecución inyecta el contexto de workspace activo y display Wayland.
* 100% de tests unitarios pasando en el workspace.
