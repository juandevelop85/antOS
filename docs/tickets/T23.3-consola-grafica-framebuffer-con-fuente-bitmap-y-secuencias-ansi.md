# T23.3 · Consola Gráfica Framebuffer en Pantalla con Fuente Bitmap y Secuencias ANSI

> **Estado:** ✅ Completado  
> **Fase:** Fase 23  
> **Fecha:** September 2026

## Descripción
Implementar un controlador de consola visual en modo texto directamente renderizado sobre el Framebuffer gráfico proporcionado por el arranque UEFI/BIOS (`boot_info.framebuffer`). En la actualidad, antOS depende fundamentalmente del puerto serie UART para mostrar el progreso de arranque, logs y mensajes del kernel, mientras que en pantalla únicamente se pinta un degradado estático. Este ticket dota al kernel de una consola gráfica completa con una fuente tipográfica bitmap incrustada (8x16), desplazamiento vertical (*scrolling*) automático de líneas, soporte de cursor y emulación de códigos de escape ANSI de colores.

## Alcance Técnico
1. **Controlador de Framebuffer Gráfico (`kernel/src/arch/x86_64/framebuffer.rs` / común):**
   - Abstracción de buffer de píxeles lineales soportando formatos comunes: `RGB` de 32 bits, `BGR` de 32 bits y formato empaquetado.
   - Manejo seguro de dimensiones de pantalla (`width`, `height`), paso de línea en bytes (`stride`) y puntero físico/virtual mapeado.
   - Rutinas primitivas de dibujado: `put_pixel(x, y, color)`, `draw_rect(x, y, w, h, color)` y copia rápida de memoria con `fast_copy`.
2. **Fuente Tipográfica Bitmap Incrustada:**
   - Incorporación de una fuente monocromática 8x16 (formato PSF v1/v2 o array de bytes constante en ROM).
   - Renderizador de caracteres `draw_char(x, y, char, foreground, background)` mediante operaciones a nivel de bit (bitmask shift).
   - Soporte para caracteres ASCII imprimibles (`32..126`) y glifos básicos extendidos (bordes de cajas Unicode y caracteres acentuados).
3. **Manejador de Consola de Texto con Desplazamiento (*Text Console*):**
   - Mantenimiento de posición actual del cursor de texto `(col, row)`.
   - Soporte para caracteres de control estándar: retorno de carro (`\r`), salto de línea (`\n`), tabulador (`\t`) y retroceso (`\x08`).
   - Implementación de desplazamiento vertical (*scrolling*): cuando el cursor sobrepasa la última fila, desplazar el contenido del framebuffer una fila hacia arriba y rellenar la última fila con el color de fondo.
4. **Parser de Códigos de Escape ANSI:**
   - Reconocimiento de secuencias de control CSI (`\x1b[...m`):
     - Colores de texto (30-37, 90-97) y colores de fondo (40-47, 100-107).
     - Atributos de texto: normal (`0`), negrita (`1`), subrayado (`4`).
     - Códigos de borrado de pantalla (`\x1b[2J`) y reposicionamiento de cursor (`\x1b[H`).
5. **Multiplexor de Salida Unificado (`kprint!` y `kprintln!`):**
   - Redefinir las macros de impresión del kernel para despachar simultáneamente los bytes a la consola serie UART y al framebuffer gráfico.
   - Sincronización mediante cerrojo de exclusión mutua (`Spinlock`) para evitar solapamiento entre múltiples hilos o interrupciones.

## Criterios de Aceptación
* El kernel muestra texto nítido, legible y formateado directamente en la ventana gráfica de QEMU o pantalla física.
* El desplazamiento vertical (*scroll*) opera sin artefactos gráficos, pérdida de texto ni caídas de rendimiento perceptibles.
* Las secuencias de escape ANSI imprimen colores correctos (rojo para errores, verde para confirmaciones, amarillo para advertencias).
* La salida del kernel se envía en paralelo tanto al puerto serie como a la pantalla gráfica.
* `cargo test --workspace` compila y se ejecuta exitosamente.
