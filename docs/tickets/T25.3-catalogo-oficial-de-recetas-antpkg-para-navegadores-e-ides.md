# T25.3 · Catálogo Oficial de Recetas antpkg para Navegadores e IDEs

> **Estado:** ⏳ Pendiente  
> **Fase:** Fase 25  
> **Fecha:** Septiembre 2026

## Descripción
Crear el catálogo curado de recetas declarativas oficiales para `antpkg` enfocado en las principales herramientas de desarrollo: navegadores web y entornos de desarrollo integrado (IDEs). Estas recetas permiten instalar aplicaciones portables directamente en el almacén inmutable de antOS (`/var/antos/store/`) con verificación estricta de sumas de verificación SHA-256, sin requerir contenedores ni privilegios de superusuario.

## Alcance Técnico
1. **Estructura de Catálogo (`recipes/` o `system/recipes/`):**
   - Crear directorio `recipes/` estructurado por categorías:
     - `recipes/browsers/firefox.toml`: Mozilla Firefox Developer / Release (binario Linux x86_64 y aarch64 con soporte Wayland nativo).
     - `recipes/browsers/chromium.toml`: Build portable oficial de Chromium.
     - `recipes/editors/vscode.toml`: Visual Studio Code (tarball oficial con script wrapper configurado para Wayland nativo `--ozone-platform=wayland`).
     - `recipes/editors/zed.toml`: Editor de código ultraligero Zed (Rust nativo Wayland).
     - `recipes/editors/cursor.toml`: Cursor AI Code Editor portable.
     - `recipes/tools/postman.toml`: Suite de APIs Postman.
2. **Estandarización de Recetas TOML:**
   - Declaración estricta de campos:
     - Checksums SHA-256 por arquitectura (`x86_64` y `aarch64`).
     - Scripts de post-extracción y creación de symlinks hacia el ejecutable principal.
     - Definición de entrada de escritorio XDG (`[desktop]`) e iconos oficiales.
     - Variables de entorno recomendadas para Wayland.
3. **Indexación y Registro en Demonio (`system/antosd/src/pkg.rs`):**
   - Incorporar el catálogo de recetas embebido o sincronizable en `antosd`.
   - Soporte para que `antos pkg install <nombre>` busque automáticamente en el catálogo oficial si el argumento no es un archivo local.
4. **Comandos CLI en antOS:**
   - `antos pkg search <término>`: Busca paquetes disponibles tanto en recetas locales como en el catálogo oficial de antOS.
   - `antos pkg info <receta>`: Inspecciona dependencias, URLs de origen y hashes criptográficos antes de instalar.
5. **Pruebas y Verificación:**
   - Pruebas automatizadas de validación sintáctica de todas las recetas TOML del catálogo.
   - Verificación de consistencia de URLs y cálculo de hashes de integridad.
   - Ejecución exitosa de `cargo test --workspace`.

## Criterios de Aceptación
* El catálogo incluye recetas funcionales y verificadas para Firefox, Chromium, VS Code, Zed y Cursor.
* `antos pkg install firefox` o `antos pkg install vscode` resuelve e instala la receta correspondiente desde el catálogo.
* Todas las recetas contienen metadatos XDG válidos y pasan la validación sintáctica.
* Cero advertencias y 100% de tests pasando en el workspace.
