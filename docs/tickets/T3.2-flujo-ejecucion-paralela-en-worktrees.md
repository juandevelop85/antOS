# T3.2 · Ejecución Paralela de Tareas en Worktrees con Validación de Tests

## Descripción
Conectar el orquestador multi-agente (`T3.1`) con la gestión de worktrees efímeros (`T2.2`) y la ejecución de tests en sandbox, permitiendo que un agente desarrolle y pruebe una funcionalidad completa en segundo plano sin interrumpir al desarrollador.

## Alcance Técnico
1. **Flujo de Ejecución Automatizado:**
   * Al recibir una tarea, `antosd` crea un worktree temporal y un sandbox con Landlock/Seatbelt.
   * El Agente Coder modifica el código dentro del worktree.
   * El Agente QA ejecuta la suite de tests (`cargo test`, `npm test`, etc.) en el recinto.
   * Si los tests fallan, el error se realimenta al Agente Coder para corregirlo (hasta un límite de reintentos).
2. **Generación de Diffs Consolidados:**
   * Al pasar los tests, se genera un diff limpio comparando el worktree contra la rama base.

## Criterios de Aceptación
* Ejecución completa en segundo plano de una tarea sencilla (ej. "añadir un test unitario a módulo X") sin intervención humana.
* Notificación final emitida con el diff verificado y tests en verde.
