# T15.3 · Gestor de Arranque UEFI y Dual Boot Automatizado

> **Estado:** ⏳ Pendiente  
> **Fase:** Fase 15  
> **Fecha:** September 2026

## Descripción
Implementación y configuración del gestor de arranque UEFI nativo (`systemd-boot` / GRUB) para el sistema instalado, incluyendo detección automática de otros sistemas operativos presentes en el equipo (`Windows Boot Manager`, otras distribuciones GNU/Linux o macOS en MacIntel), asegurando que el firmware UEFI cargue antOS de forma predeterminada pero permita al desarrollador seleccionar cualquier sistema operativo al encender el equipo sin conflictos de Secure Boot o EFI NVRAM.

## Alcance Técnico
1. **Instalador de Bootloader UEFI (`system/antosd/src/installer/bootloader.rs`):**
   - Instalación de binarios EFI en `<ESP>/EFI/antOS/antos.efi` y `<ESP>/EFI/BOOT/BOOTX64.EFI`.
   - Soporte para `systemd-boot` (ligero y estándar en systemd) y GRUB con soporte `os-prober`.
   - Registro de entrada NVRAM en el firmware UEFI mediante `efibootmgr`:
     - Comando: `efibootmgr -c -d /dev/nvme0n1 -p 1 -L "antOS" -l "\EFI\antOS\antos.efi"`.
2. **Sonda y Detección de Dual Boot (OS Prober Nativo):**
   - Búsqueda en particiones EFI de archivos típicos de arranque:
     - `EFI/Microsoft/Boot/bootmgfw.efi` -> Identificado como **Windows Boot Manager**.
     - `EFI/ubuntu/grubx64.efi` o `EFI/fedora/` -> Identificado como **Linux existente**.
   - Generación de entradas de menú de arranque automáticas con tiempos de espera configurables (`timeout 5`).
3. **Capacidades Declarativas:**
   - `bootloader.install`: Instala el cargador de arranque en la partición ESP.
   - `bootloader.probe`: Detecta sistemas operativos vecinos y genera el archivo de configuración del menú.
4. **Comandos CLI e Integración en antOS:**
   - `antos bootloader install --esp <ruta_esp>`: Instala los binarios de arranque.
   - `antos bootloader probe`: Lista los sistemas operativos detectados en la máquina.
5. **Pruebas y Verificación:**
   - Pruebas unitarias de parsing de entradas EFI y generación de archivos de configuración de `systemd-boot` (`loader.conf`, entradas `.conf`).

## Criterios de Aceptación
* El sistema genera una configuración de arranque UEFI válida con entrada predeterminada para antOS.
* Si existe Windows u otro Linux en la partición EFI, se genera automáticamente su entrada en el menú sin alterar los archivos originales.
* `cargo test --workspace` pasa al 100% sin advertencias.
* Nomenclatura e identificadores en Rust 100% en inglés.
