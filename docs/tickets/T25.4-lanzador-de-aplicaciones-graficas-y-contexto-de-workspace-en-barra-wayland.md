# T25.4 · Lanzador de Aplicaciones Gráficas y Contexto de Workspace en Barra Wayland

> **Estado:** ✅ Completado  
> **Fase:** Fase 25  
> **Fecha:** Septiembre 2026

## Descripción
Integrar un lanzador de aplicaciones rápido y contextual dentro de la barra de intenciones Wayland de antOS (`system/barra`). Cuando el usuario presiona `Super + Space`, la barra no solo debe interpretar intenciones de IA o comandos de sistema, sino también funcionar como un lanzador ágil estilo Spotlight / Raycast: detectando aplicaciones instaladas (vía `antpkg`, Flatpak o el sistema anfitrión), mostrando iconos y nombres descriptivos, y lanzándolas con inyección automática del `$ANTOS_WORKSPACE` activo para que los IDEs abran directamente el repositorio actual.

## Alcance Técnico
1. **Modo Dual en HUD de `system/barra` (`system/barra/src/main.rs`):**
   - Indexación en caché de aplicaciones instaladas al iniciar la barra consultando al socket IPC (`ListDesktopApps`).
   - Discriminación dinámica del texto ingresado en el campo de búsqueda:
     - **Coincidencia de Aplicación:** Si el texto coincide con el nombre o ejecutable de una aplicación instalada (ej. `fire` -> Firefox, `code` -> VS Code, `zed` -> Zed), la barra muestra una lista flotante de resultados con sus iconos oficiales.
     - **Intención de IA / Comando:** Si el texto es una orden o instrucción ("arregla el bug del login", "haz commit"), mantiene el flujo existente de planificación de intenciones antFlow.
2. **Navegación por Teclado y Selección:**
   - Soporte para flechas `Arriba` / `Abajo` y tecla `Tab` para navegar y autocompletar la aplicación seleccionada.
   - Presionar `Enter` en un elemento seleccionado dispara la petición IPC `LaunchDesktopApp` o ejecuta el comando con spawn asíncrono.
3. **Inyección de Contexto de Workspace:**
   - Al lanzar un editor o IDE (VS Code, Zed, Neovim), `system/barra` inyecta automáticamente la ruta del workspace activo (`$ANTOS_WORKSPACE`) como argumento o variable de entorno de apertura.
4. **Visualización y Estilos GTK4 / Layer Shell (`system/barra/src/estilo.css`):**
   - Estilos cohesivos para los ítems del lanzador:
     - Tarjeta con icono de la aplicación a la izquierda, título en negrita y categoría/fuente a la derecha (ej. `[Icono] Visual Studio Code  (antpkg)`).
     - Resaltado de selección coherente con la paleta de antOS (acentos ámbar y esmeralda).
5. **Pruebas y Verificación:**
   - Pruebas unitarias del motor de matching y filtrado de aplicaciones en memoria.
   - Verificación de no-interferencia con las funciones de intención y tablero Kanban existentes (`Super + A`).
   - Verificación de compilación del crate `system/barra` y workspace.

## Criterios de Aceptación
* `Super + Space` permite buscar aplicaciones instaladas y abrirlas con `Enter`.
* Los IDEs lanzados abren automáticamente el directorio del workspace activo en antOS.
* Coexistencia limpia entre el lanzador de aplicaciones y el motor de intenciones de IA.
* `cargo test --workspace` pasa al 100% sin regresiones.
