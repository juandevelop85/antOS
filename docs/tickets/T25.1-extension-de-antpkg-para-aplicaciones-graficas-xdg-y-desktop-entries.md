# T25.1 · Extensión de `antpkg` para Aplicaciones Gráficas XDG y Desktop Entries

> **Estado:** ✅ Completado  
> **Fase:** Fase 25  
> **Fecha:** Septiembre 2026

## Descripción
Extender el gestor de paquetes inmutable `antpkg` para admitir aplicaciones gráficas (GUI) de escritorio. Actualmente, `antpkg` solo gestiona binarios CLI enlazados hacia `/var/antos/current/bin/`. Este ticket implementa el soporte para archivos de escritorio XDG (`.desktop`), iconos (`share/icons/hicolor/`), categorías y tipos MIME en el almacén inmutable, permitiendo que navegadores, IDEs y herramientas gráficas instaladas sean descubiertas automáticamente por compositores Wayland y lanzadores de escritorio.

## Alcance Técnico
1. **Modelos y Protocolo IPC (`system/protocolo`):**
   - Ampliar `PackageManifest` con campos opcionales para aplicaciones de escritorio:
     - `desktop_entry: Option<DesktopEntryManifest>` (nombre, ejecutable, icono, categorías, comentarios, tipos MIME).
     - `app_type: PackageAppType` (`Cli`, `Gui`).
     - `icons: Vec<IconAsset>` (resolución, formato SVG/PNG, ruta relativa).
   - Extender eventos y peticiones IPC:
     - `ListDesktopApps`: Consulta todas las aplicaciones con interfaz gráfica registradas en el perfil actual.
     - `DesktopAppSummary`: Nombre visible, ID de aplicación, ejecutable, ruta de icono y categorías.
2. **Motor de Enlaces XDG en `antpkg` (`system/antosd/src/pkg.rs`):**
   - Soporte en recetas `antpkg.toml` para sección `[desktop]`:
     ```toml
     [package]
     name = "firefox"
     version = "130.0"
     app_type = "gui"

     [desktop]
     name = "Mozilla Firefox"
     generic_name = "Web Browser"
     comment = "Navegador web de código abierto"
     exec = "firefox %u"
     icon = "firefox"
     categories = ["Network", "WebBrowser"]
     mime_types = ["text/html", "application/xhtml+xml", "x-scheme-handler/http", "x-scheme-handler/https"]
     ```
   - Al instalar un paquete GUI:
     - Generar y validar el archivo `.desktop` en el almacén inmutable `/var/antos/store/<hash>/share/applications/<name>.desktop`.
     - Enlace simbólico atómico hacia `/var/antos/current/share/applications/` y `$XDG_DATA_HOME/applications/`.
     - Enlace simbólico de iconos hacia `/var/antos/current/share/icons/` y actualización de caché de iconos.
   - Al desinstalar o revertir generación (`rollback`):
     - Eliminación atómica de los enlaces `.desktop` e iconos correspondientes sin dejar entradas huérfanas.
3. **Capacidades Declarativas:**
   - `pkg.list_desktop`: Lista aplicaciones gráficas instaladas y activas.
   - `pkg.validate_desktop`: Valida la sintaxis de archivos `.desktop` según especificaciones Freedesktop.
4. **Comandos CLI en antOS:**
   - `antos pkg list --gui`: Filtra e imprime únicamente aplicaciones con interfaz gráfica instaladas.
   - `antos pkg info <paquete>`: Muestra metadatos completos, incluyendo configuración de escritorio y categorías.
5. **Pruebas y Verificación:**
   - Pruebas unitarias de generación y parseo de `.desktop`.
   - Pruebas de conmutación atómica de directorios `share/applications` y `share/icons`.
   - Compatibilidad total con `cargo test --workspace`.

## Criterios de Aceptación
* Las recetas `antpkg.toml` permiten definir metadatos XDG Desktop y rutas de iconos.
* Al instalar un paquete GUI, se generan y enlazan correctamente los archivos `.desktop` e iconos en `/var/antos/current/share/`.
* `antos pkg rollback` revierte limpiamente los accesos directos de escritorio al estado previo.
* La suite completa de pruebas del workspace compila y pasa al 100%.
