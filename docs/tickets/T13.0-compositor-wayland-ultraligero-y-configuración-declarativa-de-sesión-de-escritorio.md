# T13.0 · Compositor Wayland Ultraligero y Configuración Declarativa de Sesión de Escritorio

> **Estado:** ✅ Completado  
> **Fase:** Fase 13  
> **Fecha:** September 2026

## Descripción
Configuración y orquestación de un entorno de escritorio gráfico ultraligero (~30-40 MB de RAM) basado en un compositor Wayland (Labwc / compatible con protocolos `wlroots`) adaptado específicamente para antOS. Este entorno actúa como el pegamento gráfico del sistema, permitiendo que la barra de intenciones (`system/barra` vía `wlr-layer-shell`), el visor de diffs y terminales efímeras coexistan con editores de código y herramientas de desarrollo bajo atajos de teclado unificados.

## Alcance Técnico
1. **Configuración Declarativa del Compositor (`system/desktop/`):**
   - Definición de configuración declarativa del compositor (ej. `rc.xml` para Labwc o manifiesto equivalente):
     - Soporte obligatorio de protocolos: `wlr-layer-shell-unstable-v1` (anclaje de `antos-barra`), `wlr-screencopy-unstable-v1` (captura de buffers para QA visual) y `xdg-shell`.
     - Estilo visual minimalista, paleta de colores coherente con antOS (grises oscuros, acentos esmeralda/ámbar) y tipografía de desarrollo.
2. **Atajos de Teclado Globales del Sistema:**
   - `Super + Space`: Invoca / enfoca la barra de intenciones de antOS (`antos-barra`).
   - `Super + A`: Despliega el Centro de Agentes y Tablero de Tickets.
   - `Super + Return`: Abre terminal virtual interactiva de antOS (`vte`).
   - `Super + D`: Abre el visor interactivo de diffs y reversión (`diff_view`).
   - `Super + Q`: Cierra la ventana activa.
3. **Script de Orquestación de Sesión Gráfica (`system/desktop/start-session.sh`):**
   - Inicialización automática del demonio `antosd` en segundo plano.
   - Configuración de variables de entorno de escritorio (`XDG_CURRENT_DESKTOP=antOS`, `WAYLAND_DISPLAY`, `ANTOS_WORKSPACE`).
   - Lanzamiento coordinado del compositor y la barra de escritorio `antos-barra`.
4. **Capacidades Declarativas:**
   - `desktop.session`: Inicia o diagnostica el estado de la sesión gráfica Wayland.
   - `desktop.keys`: Muestra el listado de atajos de teclado globales registrados.
5. **Comandos CLI e Integración en antOS:**
   - `antos desktop start`: Inicia la sesión de escritorio de antOS.
   - `antos desktop status`: Informa sobre el compositor activo, displays Wayland detectados y clientes de capa (layer-shell).
   - `antos desktop keys`: Imprime en terminal la guía rápida de atajos de teclado globales.
6. **Pruebas y Verificación:**
   - Validación sintáctica de la configuración declarativa de sesión y atajos.
   - Pruebas unitarias de detección de entorno Wayland en `antosd`.

## Criterios de Aceptación
* El compositor Wayland y la sesión gráfica pueden arrancarse mediante `./system/desktop/start-session.sh` o `antos desktop start`.
* La barra de escritorio `antos-barra` se ancla correctamente como cliente `layer-shell`.
* `cargo test --workspace` pasa al 100% sin advertencias ni regresiones.
* Nomenclatura e identificadores en Rust 100% en inglés.
