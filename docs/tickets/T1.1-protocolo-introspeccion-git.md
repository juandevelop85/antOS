# T1.1 · Extensión de `antos-protocolo` para Introspección Git

## Descripción
Definir las estructuras de datos y mensajes IPC en `antos-protocolo` para soportar la consulta eficiente del estado de repositorios Git desde clientes (CLI, barras de escritorio, gestores de ventanas y agentes).

## Alcance Técnico
1. **Definición de Tipos en Rust:**
   * `GitRepoStatus`: rama actual, head commit, commits por delante/detrás del remoto, lista de archivos modificados/staged/untracked.
   * `GitFileDiffSummary`: ruta del archivo, líneas añadidas, líneas borradas, estado (`Modified`, `Created`, `Deleted`, `Renamed`).
2. **Mensajes IPC:**
   * Petición: `Mensaje::ConsultarEstadoGit { workspace_path: String }`
   * Respuesta: `Respuesta::EstadoGit(GitRepoStatus)` o `Respuesta::NoEsRepoGit`
3. **Serialización:**
   * Serialización y deserialización eficiente con `serde` y `serde_json`.

## Criterios de Aceptación
* Tests unitarios en `antos-protocolo` validando serialización/deserialización de `GitRepoStatus`.
* Compatibilidad hacia atrás con los mensajes existentes de intenciones y eventos.
