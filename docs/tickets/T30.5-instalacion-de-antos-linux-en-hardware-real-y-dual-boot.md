# T30.5 · Instalación de antOS Linux en Hardware Real y Dual-Boot

> **Estado:** ⏳ Pendiente
> **Fase:** Fase 30 (Escritorio antOS Linux — NixOS / Wayland, driver diario)
> **Fecha:** Pendiente
> **Dependencias:** T30.2 (ISO gráfica), T30.3 (userland), T15.x / T24.4 (`antos install`, particionador, gestor de arranque UEFI).

## Descripción

`antos install` (T24.4) fue diseñado para desplegar el sistema base a disco.
Este ticket lo alinea con **antOS Linux** (NixOS + escritorio antOS), no con el
kernel bare-metal: instalar desde la ISO gráfica de T30.2 a un disco físico
NVMe/SATA, con el módulo de escritorio activado, y con dual-boot seguro
preservando otros SO.

## Alcance Técnico

1. **Flujo de instalación desde la ISO de antOS Linux:**
   - `antos install` detecta discos (T15.1), ofrece **Disco Completo**
     (confirmación textual `SI`) o **Dual-Boot** (preserva ESP y particiones
     ajenas).
   - Genera un `configuration.nix` / `hardware-configuration.nix` con
     `services.antos.desktop.enable = true` y el `autologinUser` elegido en el
     asistente (paso 3 de T24.4: hostname, usuario, timezone, keymap).
   - `nixos-install` (o el equivalente del instalador) sobre el objetivo
     montado en `/mnt`, copiando el *closure* del escritorio.

2. **Gestor de arranque UEFI y dual-boot (T15.3 / T24 gestor):**
   - Entrada NVRAM `antOS Linux` vía `systemd-boot`/`efibootmgr`.
   - Detección de Windows/otros Linux y entradas de arranque coexistentes.
   - Preservar la partición ESP existente en modo Dual-Boot.

3. **Post-instalación:**
   - Primer arranque entra directo al escritorio antOS (autologin Wayland).
   - `antos doctor` verifica el recinto (`ANTOS_WORKSPACE`/`ANTOS_STATE`) y que
     `antosd` y `antos-barra` levantan.
   - `nixos-rebuild switch` disponible para que el usuario evolucione el
     sistema declarativamente (la premisa de `system/nixos/`).

4. **Documentación (`docs/guia-live-usb-e-instalacion-fisica.md` y
   `docs/manual-de-comandos.md` Método 7):**
   - Paso a paso: grabar la ISO de antOS Linux, arrancar, `antos install`,
     Disco Completo vs Dual-Boot, reinicio al escritorio.
   - Dejar explícito que este flujo instala **antOS Linux** (Método 5/ISO
     gráfica), distinto del Live del kernel bare-metal.

## Criterios de Aceptación

- Desde la ISO gráfica de T30.2 arrancada en una VM con disco virtual,
  `antos install` en modo **Disco Completo** deja un sistema que **arranca solo
  al escritorio antOS** (autologin Wayland, barra anclada, `antosd` vivo).
- En modo **Dual-Boot** con un segundo SO presente, ambos siguen arrancables y
  la ESP ajena se conserva.
- El sistema instalado permite `nixos-rebuild switch` y `antos doctor` pasa.
- La entrada de arranque `antOS Linux` queda registrada en NVRAM UEFI.
- Documentado el flujo completo, diferenciado del Live bare-metal.
- `cargo test --workspace` (crates del instalador) en verde; `cargo clippy`
  sin regresión.
