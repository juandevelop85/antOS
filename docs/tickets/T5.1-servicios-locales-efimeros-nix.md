# T5.1 · Aprovisionamiento Declarativo de Servicios Efímeros (Bases de Datos / Nix)

## Descripción
Integrar la capacidad de levantar servicios auxiliares de desarrollo (PostgreSQL, Redis, Meilisearch, RabbitMQ) de forma efímera y declarativa por proyecto usando Nix y contenedores OCI ligeros, sin requerir instalaciones globales.

## Alcance Técnico
1. **Manifiestos y Capacidades:**
   * `env.service_up.toml`: Parámetros `servicio` (*postgres*, *redis*, *mariadb*), `puerto_deseado`, `nombre_db`.
   * `env.service_down.toml`: Detiene y limpia el servicio.
2. **Orquestación con Nix / Podman:**
   * Ejecución de instancias aisladas con almacenamiento efímero en `.antos/services/<servicio>`.
   * Inyección automática de variables de conexión (`DATABASE_URL`, `REDIS_URL`) al entorno del workspace.

## Criterios de Aceptación
* `antos "levanta un postgres para este proyecto"` arranca una base de datos local aislada en segundos y devuelve la URL de conexión lista para usar.
