# T14.3 · Generador de Live ISO Autónoma, Empaquetado Release y Distribución v0.1.0

> **Estado:** ✅ Completado  
> **Fase:** Fase 14  
> **Fecha:** September 2026

## Descripción
Creación de los artefactos oficiales de distribución y despliegue del sistema operativo antOS: generador de imagen Live ISO / USB autoarrancable (con soporte para probar antOS directamente en hardware real o máquinas virtuales con entorno gráfico Wayland completo y demonio `antosd` preconfigurado), generación del `CHANGELOG.md` oficial consolidado y script de release v0.1.0 con verificación criptográfica SHA256.

## Alcance Técnico
1. **Registro Histórico Consolidado (`CHANGELOG.md`):**
   - Documento maestro con el detalle completo de las 14 fases y sus respectivos tickets entregados, arquitectura de seguridad, capacidades y filosofía de diseño.
2. **Pipeline de Empaquetado Release (`./system/build-release.sh`):**
   - Compilación optimizada `--release` de todos los binarios (`antos`, `antosd`, `antos-barra`, `builder`).
   - Reducción de tamaño mediante `strip` de símbolos ELF/Mach-O.
   - Cálculo y generación automática de sumas de verificación `SHA256SUMS`.
3. **Generador de Live ISO / USB Arrancable (`system/iso/`):**
   - Receta declarativa Nix/NixOS (`system/iso/live-image.nix`) o script de construcción de ISO basada en kernel Linux, compositor Wayland ligero (Labwc/Sway), `antos-barra` como shell y `antosd` como demonio de sistema gestionado por systemd.
   - Script de generación `./system/iso/build-iso.sh` que produce `antos-live-x86_64.iso` o `antos-live-aarch64.iso`.
4. **Tag Oficial v0.1.0:**
   - Creación del tag anotado de Git `v0.1.0` celebrando el hito de la primera versión operativa de antOS.

## Criterios de Aceptación
* El script `./system/build-release.sh` compila y genera los paquetes release y sumas SHA256 limpiamente.
* Se dispone de la receta declarativa para la Live ISO de antOS.
* `CHANGELOG.md` documenta todas las fases del proyecto.
