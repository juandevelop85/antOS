# T8.1 · Visor de Diffs Interactivo y Terminal Embebido en Wayland

> **Estado:** ✅ Completado  
> **Fase:** Fase 8  
> **Fecha:** September 2026

## Descripción
Componente gráfico en GTK4 con renderizado de diffs sintácticos coloreados, aplicación granular de parches y consola terminal VTE flotante para el shell de escritorio.

## Alcance Técnico
1. **Motor de Diffs Sintácticos y Aplicación de Parches (`DiffEngine`):**
   - Modelado de datos en `system/protocolo` (`DiffFile`, `DiffHunk`, `DiffLine`, `DiffLineKind`, `SyntaxToken`, `SyntaxTokenType`).
   - Implementado en `system/antosd/src/diff_view.rs`:
     - Parser de diffs unificados git (`parse_unified_diff`) calculando números de línea previos y nuevos, adiciones y supresiones.
     - Resaltado sintáctico inteligente (`highlight_syntax`) clasificando palabras clave, tipos, literales de cadena, comentarios y números para Rust, Python, TS/JS y polyglot.
     - Aplicador granular de parches por hunk (`apply_hunk`).
     - Renderizador de terminal ANSI con columnas de líneas dobles, cabeceras de hunk y estilo moderno.
2. **Consola Terminal Embebida y VTE (`TerminalSession`):**
   - Implementado en `system/antosd/src/vte.rs`:
     - Gestión de sesiones interactivas de terminal asociadas al shell del usuario (`/bin/zsh`, `/bin/bash`).
     - Parser de secuencias de escape ANSI (`parse_ansi_line`) para renderizado fiel de spans de texto con colores y estilos.
     - Ejecución y captura de comandos con código de salida.
3. **Estilos de Escritorio y Wayland Layer Shell (`system/barra`):**
   - Nuevos estilos en `system/barra/src/estilo.css` para el visor de diffs (`.diff-file-header`, `.diff-hunk-header`, `.diff-row`, `.diff-line-number`, `.syn-keyword`, `.syn-type`, `.syn-string`, `.syn-comment`) y la consola flotante (`.terminal-frame`, `.terminal-buffer`, `.terminal-prompt`).
   - Mensajes IPC en `system/protocolo`: `Peticion::ConsultarDiff` y `Evento::DiffEstructurado`.
4. **Capacidades Declarativas:**
   - `system/capabilities/ui.diff_viewer.toml`: Consulta y despliega el visor de diffs estructurado.
   - `system/capabilities/ui.terminal.toml`: Ejecuta comandos en la consola terminal VTE.
5. **Comandos CLI e Integración en antOS:**
   - `antos diff [objetivo]`: Renderiza diffs sintácticos coloreados con números de línea y hunks.
   - `antos terminal [comando]` / `antos vte`: Consola terminal interactiva integrada.
   - Intenciones reconocidas en lenguaje natural en el planificador local (`"muestra el diff para ticket:T8.1"`, `"abre la consola terminal interactiva"`).
6. **Pruebas y Verificación:**
   - Tests unitarios en `diff_view.rs`: `test_parse_unified_diff`, `test_syntax_highlighting`, `test_render_terminal`.
   - Tests unitarios en `vte.rs`: `test_parse_ansi_line`, `test_terminal_session_execute`.
   - Test de serialización en protocolo: `test_serializacion_diff_estructurado`.
   - Test en el planificador: `test_plan_diff_viewer_y_terminal`.
