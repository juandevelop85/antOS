# T26.5 · Runtime Soberano `libantos` y Shell Interactivo en Espacio de Usuario

> **Estado:** ⏳ Pendiente  
> **Fase:** Fase 26 (Soberanía Bare-Metal y Desktop Nativo)  
> **Fecha:** September 2026

## Descripción
Crear la biblioteca de tiempo de ejecución estándar en Rust (`libantos`) para que las aplicaciones de espacio de usuario de antOS (incluyendo el shell interactivo, herramientas de desarrollo y los componentes del orquestador antFlow) puedan compilarse y ejecutarse de forma 100% nativa sobre el kernel de antOS sin depender de la biblioteca estándar de Linux (`glibc`/`musl`). Asimismo, implementa el primer programa `init` y shell de comandos interactivo soberano de antOS que se ejecuta como PID 1 al arrancar el sistema.

## Alcance Técnico
1. **Crate de Runtime `libantos` (`system/libantos`):**
   - Implementación de `#[global_allocator]` respaldado por las llamadas al sistema `SYS_MMAP` y `SYS_MUNMAP`.
   - Soporte para tipos de la biblioteca estándar `alloc`: `Vec<T>`, `String`, `Box<T>`, `BTreeMap<K, V>`.
   - Wrappers tipados y seguros para todas las llamadas al sistema de antOS:
     - E/S estándar: `print!`, `println!`, `read_line()`.
     - Canales IPC: `Channel::create()`, `Channel::send()`, `Channel::recv()`.
     - Control de procesos: `exit()`, `yield_now()`, `getpid()`, `spawn()`.
2. **Punto de Entrada Universal de Usuario (`_start`):**
   - Ensamblador de inicialización para AArch64 y x86_64 que lee los argumentos de la pila, llama a la función `main()` del programa y finaliza con `SYS_EXIT`.
   - Manejador de pánicos `#[panic_handler]` que imprime el mensaje y ubicación del pánico en la consola antes de salir con código de error.
3. **Binario de Inicio y Shell Interactivo (`system/shell` o `antos_init`):**
   - Ejecutado por el kernel como proceso inicial (PID 1).
   - Comandos integrados (*builtins*):
     - `help`: Muestra los comandos disponibles.
     - `info`: Imprime arquitectura, versión del kernel y memoria libre.
     - `ls`: Lista archivos presentes en el VFS / ramdisk.
     - `cat`: Muestra el contenido de un archivo de texto.
     - `desktop`: Lanza o conmuta a la sesión gráfica del Desktop Shell.
     - `agent`: Inicia una intención de antFlow a través del canal IPC del kernel.
4. **Integración con `builder`:**
   - Compilar automáticamente los binarios de `libantos` y `antos_init` como parte del proceso de generación del `initrd.img`.

## Criterios de Aceptación
* `libantos` permite compilar binarios de Rust independientes para el target `aarch64-unknown-none` y `x86_64-unknown-none`.
* El proceso `init` arranca en espacio de usuario, lee entradas del usuario y responde a comandos interactivos.
* El uso de memoria dinámica (`alloc`) opera correctamente dentro del espacio de usuario mediante páginas suministradas por el kernel.
* `cargo test --workspace` compila y se ejecuta con 0 errores.
