# T2.2 · Capacidad de Gestión de Git Worktrees Efímeros para Agentes

## Descripción
Implementar la infraestructura de capacidades para crear, aislar y limpiar *Git Worktrees* temporales donde los sub-agentes de IA puedan modificar código, compilar y ejecutar tests en paralelo sin interferir con el espacio de trabajo principal del desarrollador.

## Alcance Técnico
1. **Manifiestos en `system/capabilities/`:**
   * `git.worktree_create.toml`: Crea un clon de trabajo en un directorio efímero (`~/.cache/antos/worktrees/<ticket_id>`).
   * `git.worktree_cleanup.toml`: Elimina el worktree tras aprobación o descarte.
   * `git.worktree_merge.toml`: Integra los cambios aprobados a la rama de destino.
2. **Ejecutores en `antosd`:**
   * Llamadas nativas a Git para la creación/eliminación atómica de árboles de trabajo.
3. **Sandbox Específico:**
   * El recinto de ejecución del agente queda limitado exclusivamente al directorio del worktree temporal.

## Criterios de Aceptación
* Creación de un worktree aislado en menos de 500 ms compartiendo el objeto `.git` del repositorio base.
* Aislamiento total: un agente modificando archivos en el worktree no altera los archivos del workspace activo en el editor.
