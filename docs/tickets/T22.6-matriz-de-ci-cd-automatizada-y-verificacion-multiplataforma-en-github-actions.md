# T22.6 · Matriz de CI/CD Automatizada y Verificación Multiplataforma en GitHub Actions

> **Estado:** ✅ Completado  
> **Fase:** Fase 22  
> **Fecha:** September 2026

## Descripción
Establecer un flujo completo y automatizado de Integración y Entrega Continua (CI/CD) para antOS mediante GitHub Actions (`.github/workflows/ci.yml`). Dada la naturaleza híbrida del proyecto (crates en userspace para macOS y Linux, junto a un kernel bare-metal `no_std` en x86_64 y AArch64 y un generador de imágenes UEFI), es imperativo asegurar que cada pull request o commit garantice la salud del código en todas las plataformas y arquitecturas objetivo sin regresiones silenciosas.

## Alcance Técnico
1. **Flujo de Trabajo Principal (`.github/workflows/ci.yml`):**
   - Disparadores configurados para `push` a ramas principales y `pull_request`.
2. **Matriz de Construcción y Pruebas para Userspace:**
   - **Job Linux (`ubuntu-latest`):**
     - Instalación de dependencias del sistema: `libgtk-4-dev`, `libgtk4-layer-shell-dev`, `qemu-system-x86`, `qemu-system-arm`.
     - `cargo check --workspace` y `cargo test --workspace`.
     - Verificación de políticas y recintos Landlock LSM en entorno Linux real.
   - **Job macOS (`macos-14` / Apple Silicon):**
     - `cargo test --workspace` para validar recintos Seatbelt, supervisor RSS y aislamiento de sandboxing en Darwin.
3. **Validación de Compilación Cruzada Bare-Metal (`kernel`):**
   - Instalación de targets `rustup target add x86_64-unknown-none` y `aarch64-unknown-none`.
   - Compilación del kernel con `cargo build --manifest-path kernel/Cargo.toml --target x86_64-unknown-none`.
   - Compilación del kernel con `cargo build --manifest-path kernel/Cargo.toml --target aarch64-unknown-none`.
4. **Validación del Ensamblador de Imágenes (`builder`):**
   - Ejecución de pruebas unitarias de `builder` para verificar la creación de discos GPT y partición EFI FAT32.
5. **Auditoría de Calidad y Formato:**
   - `cargo fmt --all -- --check`: Garantiza estilo de código uniforme.
   - `cargo clippy --workspace --all-targets -- -D warnings`: Previene antipatrones o advertencias de compilador.
   - `cargo clippy --manifest-path kernel/Cargo.toml --target x86_64-unknown-none -- -D warnings`.

## Criterios de Aceptación
* Se crea el archivo `.github/workflows/ci.yml` configurado con la matriz completa de validación.
* Se ejecutan y validan las pruebas en Linux y macOS en paralelo.
* Se verifica la compilación cruzada del kernel bare-metal para x86_64 y AArch64.
* Los chequeos de `clippy` y `rustfmt` se aplican con rigor de advertencias cero.
* El pipeline completo finaliza en verde.
