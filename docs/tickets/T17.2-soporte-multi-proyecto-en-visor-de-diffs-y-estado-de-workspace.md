# T17.2 · Soporte Multi-Proyecto en Visor de Diffs y Estado de Workspace

> **Estado:** ⏳ Pendiente  
> **Fase:** Fase 17  
> **Fecha:** September 2026

## Descripción
Adaptar el comando `antos diff`, el despachador IPC `QueryDiff` y la capacidad `ui.diff_viewer` para que operen a nivel de proyecto del desarrollador en lugar de asumir un único repositorio global. Permitir inspeccionar diffs de un proyecto específico (ej. `antos diff api-service [target]`), detectar automáticamente el proyecto según el directorio actual (`cwd`) o escanear todos los proyectos presentes en `workspace/` si se ejecuta desde la raíz, reportando tanto diffs de repositorios Git como archivos detectados en proyectos aún no inicializados en control de versiones.

## Alcance Técnico
1. **Comando CLI `antos diff` en `system/antosd/src/main.rs`:**
   - Soporte para sintaxis `antos diff [proyecto_o_ruta] [target_ref]`.
   - Detección automática del proyecto actual si la terminal está dentro de `workspace/<proyecto>`.
   - Escaneo iterativo de proyectos en `workspace/` si no se especifica proyecto y se ejecuta desde la raíz.
   - Reporte informativo claro cuando un proyecto contiene archivos pero aún no tiene Git inicializado (con sugerencias para inicializarlo).
2. **Capacidad `ui.diff_viewer` y `Change::UiDiffViewer` en `system/antosd/src/exec.rs`:**
   - Parámetro opcional `project` en el manifiesto `ui.diff_viewer.toml`.
   - Ejecución aislada sobre el directorio del proyecto especificado con `GIT_CEILING_DIRECTORIES`.
3. **Despachador IPC en `system/antosd/src/ipc.rs`:**
   - Adaptar `Request::QueryDiff` para aceptar `project_path: Option<String>`.
4. **Pruebas y Verificación:**
   - Pruebas unitarias de resolución de rutas por proyecto, escaneo de workspace y renderizado de diffs en subproyectos aislados.

## Criterios de Aceptación
* `antos diff api-service` muestra exclusivamente los cambios del proyecto `api-service` ubicado en `workspace/api-service`.
* `antos diff` ejecutado desde la raíz de antOS o de `workspace` analiza los proyectos del desarrollador y no muestra cambios de los archivos del sistema operativo.
* Si un proyecto en `workspace` no tiene `.git`, `antos diff` muestra un resumen limpio de archivos detectados y sugiere ejecutar `git init`.
* 100% de compatibilidad con `cargo test --workspace`.
