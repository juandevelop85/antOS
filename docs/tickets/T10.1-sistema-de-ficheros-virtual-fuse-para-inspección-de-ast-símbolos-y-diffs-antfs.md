# T10.1 · Sistema de Ficheros Virtual FUSE para Inspección de AST, Símbolos y Diffs (/antfs)

> **Estado:** ⏳ Pendiente  
> **Fase:** Fase 10  
> **Fecha:** September 2026

## Descripción
Implementación de un sistema de ficheros virtual en espacio de usuario mediante FUSE (`/antfs`) que proyecta el código del espacio de trabajo no como ficheros planos, sino como jerarquías navegables de símbolos, funciones, tipos, grafos de llamadas y estados de Git en tiempo real.

## Alcance Técnico
1. **Driver VFS en Espacio de Usuario (`system/antosd/src/vfs/`):**
   - Integración con FUSE para Linux y macOS (con fallback de visor CLI cuando no haya módulo de kernel FUSE).
   - Estructura de directorios virtuales:
     - `/antfs/symbols/<tipo>/<nombre_simbolo>` (ej. `structs/ResourceQuota`, `functions/parse_unified_diff`).
     - `/antfs/graph/<modulo>/callers` y `/antfs/graph/<modulo>/callees`.
     - `/antfs/git/uncommitted/` (proyección virtual de archivos modificados con sus diffs).
2. **Generador Semántico Dinámico:**
   - Conexión directa con `MemoryEngine` y el parser sintáctico para construir los inodos virtuales en memoria bajo demanda.
3. **Capacidades Declarativas:**
   - `vfs.mount`: Monta el sistema de ficheros virtual en un punto de montaje (ej. `.antos/mnt`).
   - `vfs.unmount`: Desmonta de forma segura el punto FUSE.
   - `vfs.query`: Consulta símbolos navegables desde CLI sin necesidad de montar FUSE.
4. **Comandos CLI e Integración en antOS:**
   - `antos vfs mount [ruta]`: Monta `/antfs` en el punto de montaje indicado.
   - `antos vfs symbols`: Lista los símbolos indexados en el VFS.
5. **Pruebas y Verificación:**
   - Pruebas unitarias de resolución de rutas virtuales a símbolos.
   - Pruebas de lectura simulada de inodos virtuales.

## Criterios de Aceptación
* Las rutas virtuales devuelven el fragmento de código exacto y metadatos del símbolo consultado.
* `cargo test --workspace` pasa al 100% sin advertencias.
* Nomenclatura e identificadores en Rust 100% en inglés.
