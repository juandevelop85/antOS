# T26.2 · Desktop Shell Nativo en Rust y Compositor 2D sobre Framebuffer

> **Estado:** ⏳ Pendiente  
> **Fase:** Fase 26 (Soberanía Bare-Metal y Desktop Nativo)  
> **Fecha:** September 2026

## Descripción
Implementar el primer entorno de escritorio gráfico soberano para antOS, escrito 100% en Rust (`no_std`) y renderizado directamente sobre el Framebuffer gráfico sin requerir X11, Wayland de Linux ni librerías C (`gtk4`, `glib`, `cairo`). El Desktop Shell ofrece una experiencia visual completa: barra de estado superior fija, HUD flotante de intenciones, ventana de terminal interactiva con soporte de fuentes bitmap y buffer doble (*backbuffering*) para eliminar el parpadeo (*tearing*).

## Alcance Técnico
1. **Compositor y Renderizador 2D en Rust (`kernel/src/ui/`):**
   - Sistema de coordenadas y rectángulos (`Rect { x, y, width, height }`).
   - Primitivas gráficas: `fill_rect`, `draw_border`, `draw_rounded_box`, sombras sutiles y línea divisoria.
   - Soporte para doble buffer en memoria RAM (`backbuffer`): todas las operaciones de dibujo ocurren en memoria y se copian al Framebuffer físico en un solo ciclo atómico (`present()`).
2. **Barra de Estado Superior de antOS:**
   - Altura: 28 píxeles. Fondo oscuro translúcido (`#161b22`).
   - Sección Izquierda: Logotipo antOS (`🐜 antOS`), estado de la HAL (`AArch64 / x86_64`) y estado del planificador.
   - Sección Central: Espacio de trabajo activo y título de la ventana enfocada.
   - Sección Derecha: Indicador de uso de Heap en tiempo real, pulsos de temporizador (ticks) y reloj.
3. **HUD Flotante de Intenciones de Desarrollo (Estilo antOS-Barra):**
   - Panel modal centrado con marco resaltado (`#58a6ff`).
   - Campo de entrada con cursor parpadeante para ingresar comandos o intenciones al sistema.
4. **Ventana de Terminal Gráfica Embebida:**
   - Ventana móvil con barra de título, botones de control (cerrar/minimizar) y área de texto.
   - Emulación de terminal VT100/ANSI integrada con la fuente bitmap 8x16.

## Criterios de Aceptación
* El escritorio se renderiza en la pantalla gráfica mostrando barra de estado, terminal y HUD flotante.
* La técnica de *backbuffering* previene parpadeos durante el redibujado de la pantalla.
* La paleta de colores respeta el tema oficial oscuro (*antOS Dark Theme*).
* Pruebas unitarias de composición geométrica y cálculo de coordenadas en `ui`.
