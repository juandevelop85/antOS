# T20.4 · Snapshots Atómicos de Entorno de Desarrollo y Time Machine de Estado

> **Estado:** ⏳ Pendiente  
> **Fase:** Fase 20  
> **Fecha:** September 2026

## Descripción
Implementar el motor de instantáneas atómicas de desarrollo y "Time Machine" de estado (`antos snapshot`), permitiendo congelar y restaurar en menos de 200 ms el estado completo del entorno de trabajo: árbol de código (incluidos archivos sin seguimiento / untracked), estado y datos de bases de datos de servicios locales efímeros (PostgreSQL, Redis), variables de entorno activas y grafo de memoria vectorial. Esto otorga al desarrollador y a los agentes total libertad para realizar refactorizaciones o pruebas destructivas con capacidad de rollback garantizado.

## Alcance Técnico
1. **Motor de Snapshotting Atómico (`system/antosd/src/time_machine/`):**
   - Captura diferencial de archivos en workspace: almacenamiento deduplicado de blobs en `.antos/snapshots/<hash>/`.
   - Volcado rápido de estado de servicios efímeros (`$STATE/services/` data dirs).
   - Instantánea del estado de la memoria semántica (`context_graph.db`).
   - Metadatos del snapshot: nombre/etiqueta, autor (humano o agente), timestamp, rama y commit base de Git.
2. **Restauración Atómica e Inversión de Estado:**
   - `restore`: Devuelve el workspace, archivos de código y bases de datos al punto exacto del snapshot.
   - Seguridad: Si hay cambios no confirmados al intentar restaurar, se solicita confirmación o se crea un snapshot de rescate previo automático.
3. **Integración con antFlow (Checkpoints de Agentes):**
   - Creación automática de un checkpoint antes de que el rol *Coder* aplique modificaciones complejas.
   - Si el rol *QA* o el *Auditor* detectan fallos irreparables o el humano rechaza (`antos agent reject`), se ejecuta un rollback total al snapshot previo sin dejar residuos.
4. **Comandos CLI:**
   - `antos snapshot create [etiqueta]`: Guarda una instantánea del estado actual.
   - `antos snapshot list`: Muestra la cronología de instantáneas, tamaños y ramas asociadas.
   - `antos snapshot restore <id|etiqueta>`: Revierte el entorno completo a ese estado.
   - `antos snapshot delete <id>`: Elimina una instantánea liberando espacio.
5. **Pruebas y Verificación:**
   - Pruebas unitarias de creación, listado y restauración de archivos y estado en sandbox temporal.
   - Verificación de no corrupción de bases de datos SQLite durante la reversión.

## Criterios de Aceptación
* `antos snapshot create` genera una instantánea completa recuperable.
* `antos snapshot restore` devuelve los archivos y estado al punto capturado de forma limpia.
* Los agentes de antFlow utilizan los snapshots para asegurar rollback instantáneo ante rechazo de planes.
* `cargo test --workspace` pasa al 100% sin advertencias ni regresiones.
