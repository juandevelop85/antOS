# T7.2 · Control de Cuotas de CPU y Memoria para Sandboxes de Agentes

> **Estado:** ✅ Completado  
> **Fase:** Fase 7  
> **Fecha:** September 2026

## Descripción
Aislamiento de recursos a través de cgroups v2 en Linux y límites de tiempo/memoria en Seatbelt para evitar bloqueos por bucles infinitos en ejecuciones de agentes.

## Alcance Técnico
1. **Modelado y Tipado de Cuotas (`ResourceQuota`):**
   - Implementado en `system/antosd/src/sandbox/quota.rs`.
   - Campos configurables:
     - `timeout_secs`: Límite duro de tiempo de ejecución para prevenir bucles infinitos de agentes (por defecto 120s).
     - `max_memory_mb`: Límite máximo de memoria residente (RSS) para prevenir desbordamientos o fugas OOM (por defecto 1024 MB).
     - `cpu_quota_percent`: Cuota porcentual de CPU (por defecto 100%).
     - `max_pids`: Límite de procesos concurrentes para prevenir fork-bombs (por defecto 64 procesos).
2. **Aislamiento Multi-Plataforma:**
   - **Linux (cgroups v2):** Controlador `CgroupV2Manager` que configura `memory.max`, `cpu.max` y `pids.max` en `/sys/fs/cgroup/antos/<tarea>/`.
   - **macOS / Seatbelt + Supervisor de Procesos:** `ProcessWatchdog` inspecciona el proceso en ejecución en intervalos de 50ms, monitorea el consumo de memoria RSS (`read_process_rss_mb`) y aplica corte forzado (`SIGKILL`) si el agente excede el timeout o la memoria asignada.
   - Integración nativa en `sandbox::run` asegurando que toda ejecución de capacidades en el sandbox esté gobernada por las cuotas de recursos.
3. **Capacidades Declarativas:**
   - `system/capabilities/quota.status.toml`: Inspecciona cuotas y mecanismo activo en el host.
   - `system/capabilities/quota.set.toml`: Modifica cuotas y límites persistentes en `$WORKSPACE/.antos/quota.toml`.
4. **Comandos CLI e Integración en antOS:**
   - `antos quota status` / `antos quota`: Muestra mecanismo activo, timeout, memoria, CPU y límite de PIDs.
   - `antos quota set [--timeout N] [--memory N] [--cpu N] [--pids N]`: Modifica cuotas.
   - `antos quota reset`: Restaura los valores de fábrica seguros de antOS.
   - Planificador local reconoce intenciones en lenguaje natural (`"muestra las cuotas de recursos del sandbox"`, `"establece timeout 60 y memoria 512"`).
5. **Pruebas y Verificación:**
   - Tests unitarios en `quota.rs`: `test_quota_defaults`, `test_save_and_load_quota`, `test_watchdog_timeout_enforcement`.
   - Test de integración en el planificador: `test_plan_quota_status_y_set`.
