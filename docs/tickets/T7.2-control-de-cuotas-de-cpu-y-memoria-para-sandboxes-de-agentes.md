# T7.2 · Control de Cuotas de CPU y Memoria para Sandboxes de Agentes

> **Estado:** ⏳ Pendiente

## Descripción
Aislamiento de recursos a través de cgroups v2 en Linux y límites de tiempo/memoria en Seatbelt para evitar bloqueos por bucles infinitos en ejecuciones de agentes.
