# T14.2 · Agente Multimodal con Captura de Pantalla Wayland para Inspección y QA Visual

> **Estado:** ✅ Completado  
> **Fase:** Fase 14  
> **Fecha:** September 2026

## Descripción
Incorporación del rol `VisualQA` en el flujo de agentes de `antFlow`, dotando al sistema de capacidad para capturar ventanas o el escritorio Wayland mediante protocolos estándar (`wlr-screencopy` / XDG Desktop Portal) e interpretar la interfaz gráfica utilizando modelos de visión locales (Llava, Moondream, MiniCPM-V vía Ollama) o remotos, detectando fallos de diseño, desalineaciones CSS, errores en runtime visuales y verificando flujos de usuario completos.

## Alcance Técnico
1. **Capturador de Pantalla Wayland (`system/antosd/src/vision/`):**
   - Protocolo de captura de frames Wayland (`wlr-screencopy-unstable-v1`) con codificación a PNG / JPEG en memoria.
   - Soporte de recorte por ventana/geometría de proceso específico.
2. **Pipeline de Inferencia Multimodal en `antFlow`:**
   - Rol `AgentRole::VisualQA` añadido a la máquina de estados.
   - Envío de imagen en base64 junto con el prompt del sistema al endpoint `/api/generate` de Ollama con soporte multimodal.
   - Generación de reportes de auditoría visual con anotaciones de coordenadas y severidad de bugs.
3. **Capacidades Declarativas:**
   - `ui.screenshot`: Captura la pantalla o ventana del proceso bajo prueba con confirmación requerida.
   - `ui.inspect_visual`: Evalúa la captura contra criterios de aceptación visuales.
4. **Comandos CLI e Integración en antOS:**
   - `antos qa visual [target]`: Lanza una inspección visual de la aplicación en ejecución.
5. **Pruebas y Verificación:**
   - Pruebas unitarias de codificación y compresión de imágenes.
   - Parsing de respuestas multimodales estructuradas de LLM.

## Criterios de Aceptación
* El agente `VisualQA` puede capturar una ventana de aplicación y formular un diagnóstico visual fundamentado.
* `cargo test --workspace` pasa al 100% sin advertencias.
* Nomenclatura e identificadores en Rust 100% en inglés.
