# T30.2 · Imagen Gráfica de VM e ISO de antOS Linux

> **Estado:** 🔄 En Progreso
> **Fase:** Fase 30 (Escritorio antOS Linux — NixOS / Wayland, driver diario)
> **Fecha:** September 2026
> **Dependencias:** T30.1 (paquete y módulo de sesión). Reutiliza `system/nixos/vm.nix` y `system/arrancar-vm.sh`.

## Descripción

`system/nixos/vm.nix` construye hoy una VM **sin gráficos** (`graphics = false`,
consola serie). Para que antOS Linux sea el escritorio de uso diario hace falta
una imagen que arranque **directa al escritorio antOS** (Labwc + `antos-barra`)
en una VM y, opcionalmente, una ISO instalable/Live.

## Alcance Técnico

1. **VM gráfica (`system/nixos/vm.nix` + variante):**
   - `virtualisation.graphics = true`, `qemu.options` con
     `-device virtio-gpu-pci` (o `virtio-vga-gl`), `-display gtk,gl=on` /
     `cocoa` en macOS, `-usb -device usb-tablet`, memoria ≥ 2 GiB.
   - Mesa + `virtio_gpu` KMS en el *guest* (`hardware.opengl.enable = true`,
     `boot.initrd.kernelModules`/`availableKernelModules` con `virtio_gpu`).
   - `services.antos.desktop.enable = true` con `autologinUser`.
   - Resultado: `nixos-rebuild build-vm` (o `nix build .#vm`) produce un guion
     que lanza QEMU y aparece el escritorio antOS sin pasos manuales.

2. **`system/arrancar-vm.sh`:**
   - Flag `--grafica` (por defecto sigue *headless* para CI/serie).
   - En `--grafica`: construye la variante gráfica y lanza QEMU con `virtio-gpu`
     + `usb-tablet`; documenta el atajo para soltar el ratón.
   - Detección de `qemu-system-x86_64` / `qemu-system-aarch64` y del backend
     de display por SO anfitrión.

3. **ISO de antOS Linux (`system/nixos/iso.nix`, opcional en este ticket si el
   tiempo aprieta — mínimo dejar el andamiaje):**
   - `modulesPath/installer/cd-dvd/installation-cd-graphical-base.nix` +
     `services.antos.desktop.enable`.
   - `nix build .#iso` produce `antos-linux-<arch>.iso` arrancable en hardware
     y en UTM/VirtualBox, con la sesión antOS y el instalador disponible.
   - Distinguir claramente de `antos usb build` (que empaqueta el kernel
     **bare-metal**, "Método 6"): esta ISO es **antOS Linux**, "Método 5".

4. **Documentación (`docs/manual-de-comandos.md` Método 5 y
   `docs/guia-emulacion-utm-virtualbox.md`):**
   - Cómo arrancar la VM gráfica y (si existe) la ISO en QEMU, UTM y
     VirtualBox, con los `-device` de GPU/entrada exactos y el resultado
     esperado (escritorio antOS con la barra anclada).

## Criterios de Aceptación

- `system/arrancar-vm.sh --grafica` construye y arranca una VM que **muestra el
  escritorio antOS** (compositor Labwc + `antos-barra` anclada) sin
  intervención manual, con ratón y teclado funcionando.
- La VM *headless* (`system/arrancar-vm.sh` sin flags) sigue arrancando por
  serie sin regresión.
- El *guest* usa aceleración `virtio-gpu`/Mesa (comprobable con
  `wayland-info` / `glxinfo` equivalentes o el log de Labwc).
- Si se incluye la ISO: `nix build .#iso` produce un `.iso` que arranca al
  escritorio antOS en QEMU y en UTM/VirtualBox.
- Documentado el comando exacto por hipervisor y el resultado esperado.
- No hay regresión en la evaluación Nix (`nixos-rebuild build`) ni en
  `cargo check --workspace`.

   `${modulesPath}/installer/cd-dvd/installation-cd-graphical-base.nix`,

   `image.fileName = "antos-linux-<ver>.iso"`, `volumeID = ANTOS_LINUX`,
   `hostName = antos-live`.
3. **`flake.nix`** — refactor: se separa `nucleo` (módulos antOS + overlay)

   `nixosConfigurations.antos-iso` + `packages.<arch>.iso` (`isoPara`).
