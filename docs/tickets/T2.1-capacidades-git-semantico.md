# T2.1 · Capacidades Tipadas para Git Semántico (`status`, `commit_semantic`, `branch`)

## Descripción
Crear los manifiestos declarativos y los ejecutores en `antosd` para operaciones comunes de Git orientadas a desarrollo asistido por IA, garantizando que el modelo opere a través de parámetros tipados y no con comandos de shell arbitrarios.

## Alcance Técnico
1. **Manifiestos en `system/capabilities/`:**
   * `git.status.toml`: Inspección estructurada de estado.
   * `git.commit_semantic.toml`: Parámetros `tipo` (*feat*, *fix*, *docs*, *refactor*, etc.), `alcance` opcional, `mensaje` y `archivos`.
   * `git.smart_branch.toml`: Parámetros `nombre_rama`, `base_rama`, `asociar_ticket`.
2. **Ejecutores en `antosd`:**
   * Implementación de la lógica de ejecución en sandbox con validación previa de efectos.
3. **Validación de Radio de Impacto:**
   * Las operaciones de escritura solo pueden mutar el `.git` y los archivos dentro del `$WORKSPACE`.

## Criterios de Aceptación
* Invocación de `antos "haz commit con los cambios de auth"` genera un plan con `git.commit_semantic` y diff revisable.
* La acción es completamente auditable y registrada en la bitácora.
