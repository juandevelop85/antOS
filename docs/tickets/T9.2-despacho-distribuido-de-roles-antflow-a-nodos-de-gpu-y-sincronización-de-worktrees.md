# T9.2 · Despacho Distribuido de Roles antFlow a Nodos de GPU y Sincronización de Worktrees

> **Estado:** ✅ Completado  
> **Fase:** Fase 9  
> **Fecha:** September 2026

## Descripción
Capacidad de delegar tareas intensivas del orquestador `antFlow` (como generación de código mediante modelos LLM pesados de 70B parámetros en el rol Coder, o suites de pruebas de integración masivas en QA) a nodos remotos de la malla `antMesh`, sincronizando de forma transparente los worktrees de Git mediante deltas comprimidos.

## Alcance Técnico
1. **Planificador Distribuido de Carga (`system/antosd/src/flow/distributed.rs`):**
   - Heurística de selección de nodo basada en disponibilidad de VRAM, carga de CPU y latencia de red.
   - Despacho de subtareas del orquestador con seguimiento de timeouts y cuotas remotas.
2. **Sincronización P2P de Git Worktrees:**
   - Creación de paquetes de deltas binarios entre ramas efímeras de agentes (`git bundle` o transferencia de objetos Git directa sobre QUIC).
   - Aplicación aislada en el sandbox del nodo receptor.
3. **Capacidades Declarativas:**
   - `flow.dispatch_remote`: Despacha un rol específico (`Coder`, `QA`) a un peer seleccionado.
   - `flow.swarm_status`: Visualiza la matriz de distribución de agentes en la malla.
4. **Comandos CLI e Integración en antOS:**
   - `antos agent run T1.1 --node <node-id>`: Fuerza la ejecución de un ticket en un nodo específico.
   - `antos swarm`: Monitor de carga de trabajo distribuida y agentes en ejecución remota.
5. **Pruebas y Verificación:**
   - Prueba unitaria de serialización de asignación de tareas remotas.
   - Mock de sincronización de deltas de worktree entre dos repositorios temporales.

## Criterios de Aceptación
* El orquestador antFlow puede alternar la ejecución de roles entre local y remoto sin alterar la máquina de estados.
* La sincronización de cambios se realiza de forma segura respetando las concesiones de la bóveda de secretos.
* `cargo test --workspace` pasa al 100% sin advertencias.
* Nomenclatura e identificadores en Rust 100% en inglés.
