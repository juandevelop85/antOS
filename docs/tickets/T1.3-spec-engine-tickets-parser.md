# T1.3 · Indexador y Parser Nativo de Especificaciones y Tickets Markdown

## Descripción
Construir un subsistema en `antosd` que indexe automáticamente las carpetas de especificaciones (`docs/tickets/`, `specs/`) del workspace, extrayendo metadatos estructurados (ID, título, fase, estado, dependencias entre tareas) para su consumo por agentes y la UI.

## Alcance Técnico
1. **Parser de Tickets Markdown:**
   * Detección de patrones de nombres (`T[Fase].[ID]-*.md`).
   * Extracción de encabezados, estado (*Pendiente*, *En Progreso*, *Completado*), descripción y criterios de aceptación.
2. **Estructuras en `antos-protocolo`:**
   * Tipos `TicketSummary`, `TicketDetail`, `TicketStatus`.
   * Mensajes IPC: `ListarTickets { workspace_path }` y `ObtenerTicket { ticket_id }`.
3. **Watcher de Archivos:**
   * Actualización en tiempo real del índice cuando se crean o modifican archivos de tickets.

## Criterios de Aceptación
* El comando `antos tickets` lista correctamente los tickets del proyecto actual en la terminal.
* Cambios en el markdown de un ticket se reflejan inmediatamente en las consultas IPC.
